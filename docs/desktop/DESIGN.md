# Spark macOS 桌面端 UI 样式与视觉规范

- **版本**：v0.8（新版 macOS 原生客户端设计定稿）
- **更新日期**：2026-11-22
- **状态**：设计基线。现有原生候选和已验证的视觉项目见 [桌面入口](README.md)
- **视觉基准**：与在线 Web「灵光手帐」视觉体系同源（见 [WEB-VISUAL.md](../design/WEB-VISUAL.md) 与 [apps/web/src/styles/tokens.css](../../apps/web/src/styles/tokens.css)），在此基础上针对 macOS 菜单栏常驻、悬浮随手记浮层与原生窗口栏做克制精修。

---

设备设置用四张色卡选择手帐配色，以分段单选控件选择明暗模式。全局快捷键保留系统下拉选择器，选项以 macOS 键帽符号显示。三组控件均支持键盘操作。

## 1. 视觉原则

1. **低存在感，高响应感**：平时只以一枚 18×18pt 单色小瓶子驻留菜单栏，不挂未读数字红点、不抢视线；呼出时像一张刚好递到手边的手帐便签纸，写完立刻收走。
2. **一处温暖个性，其余绝对克制**：保留 Spark 标志性的小瓶子标志、四套手帐配色、点阵手帐纸（主窗口）与 6 色项目纸胶带；控件边界、字体、圆角与间距保持安静整齐。
3. **颜色传达确定语义**：
   - `--sp-primary`：主操作（「收下」「连接」「记一条」）、当前导航、键盘焦点环；
   - `--sp-spark`（第二色）：灵光点缀（收集框顶部细胶带、AI 整理提示、剪贴板轻建议强调、刚刚保存成功光晕）；
   - `--sp-tape-1..6`：仅用于标识项目，按项目 UUID 哈希稳定映射，不存储、不可手动改色；
   - `--sp-warning` / `--sp-danger`：仅用于本地待同步提示、401 暂停、需人工核对或输入超限，不渲染假状态。
4. **双层外观同步**：支持 `data-palette`（`mint | sea | matcha | sakura`）× `data-mode`（`light | dark`，解析自 `system | light | dark`），首帧渲染前即设置 `<html>` 属性，禁止白屏闪烁。

## 3. 五大核心界面像素级规格

### 3.1 菜单栏图标（`NSStatusItem`）

- **图形**：采用与 Web 一致的 Spark 小瓶子轮廓（[Brand.tsx](../../apps/web/src/components/Brand.tsx) 的 `JarGlyph` 简化单色线条版），画布 `18×18pt`（输出 `@2x` 36×36px 与 `@3x` 54×54px PNG），设置 `NSImage.template = YES`，由 macOS 自动适配浅色/深色/壁纸菜单栏。
- **状态视觉**（严禁显示数字红点）：
  - **正常静息态**：纯单色小瓶子，无额外装饰。
  - **本机待同步态（离线暂存 > 0）**：小瓶子右下角叠加 `4pt` 实心圆点（模板态切为非模板或绘入单色微点，低干扰）。
  - **需关注态（401 会话过期或 `needs_review > 0`）**：小瓶子右下角显示 `5pt` 暖橙/警示点（`#d97706`）。
  - **收下轻闪反馈**：静默收下（如拖拽松手）时，瓶内灵光点亮 `450ms` 后恢复静息态，不弹系统通知横幅。
  - **拖拽悬停态**：文件/文字拖入菜单栏图标区域时，图标轻微高亮底框（系统选中态）。

### 3.2 悬浮随手记面板（Quick Capture Panel）

这是用户每天使用最高频的界面，**目标是在 1–5 秒内完成记录并消失**。

#### 窗口外框与几何
- **窗口尺寸**：固定宽度 `460px`；高度随内容自适应，最小 `156px`，最大 `560px`（超出时仅内部滚动，不拉爆屏幕）。
- **无系统边框**：无红黄绿灯、无原生标题栏；WebView 透明背景（`drawsBackground = NO`），内容根容器在透明窗口内留出 4px，绘制纸面、圆角与细描边。输入框聚焦时只强调纸面外缘。
- **顶部装饰胶带**：卡片左上角内缩 `20px` 贴一段 `36px × 5px`、圆角 `0 0 4px 4px` 的第二色（`--sp-spark`）小胶带，无文字，既建立「灵光手帐」识别度又不占高度。
- **呼出定位**：
  - `⌥Space` 呼出：水平居中于当前活跃鼠标所在屏幕，垂直位于屏幕高度上方约 `22%` 处（视线自然落点，非正中死板居中）。
  - 点击菜单栏图标呼出：锚定在菜单栏图标正下方 `6px` 处（右侧距离屏幕右边至少 `12px`）。

#### 各区域详细样式规格
1. **主输入区（`capture-editor`）**：
   - Padding：`16px 18px 10px`；无独立边框与背景，直接写在纸面上。
   - 高度：默认 3 行视觉高度（`min-height: 72px`），随文本自动增高至 `max-height: 220px`，超过后内部平滑滚动（细滚动条 `5px`）。
   - Placeholder 颜色 `--sp-muted`（不透明度 `0.78`），文案：「记下想法、粘贴链接或截图…」。
2. **剪贴板 20 秒轻建议胶囊（`clipboard-pill`）**：
   - 位于输入区正下方，外边距 `0 16px 10px`。
   - 高度 `32px`，圆角 `--sp-radius-pill`，背景 `--sp-spark-soft`（浅色）/`--sp-surface-muted`（深色），边框 `1px solid var(--sp-spark-strong)`（透明度 35%）。
   - 内含：14px 图标（图片/链接/文字）+ 单行截断预览（`max-width: 240px`，`text-overflow: ellipsis`）+ 右侧等宽键帽徽章 `Tab`（`height: 20px`，`padding: 0 6px`，`border-radius: 5px`，白底/深次底 + 细边框）+ `18×18` 关闭按钮 `×`。
   - 动效：`140ms var(--sp-ease-out)` 从 `translateY(-4px); opacity: 0` 淡入。
3. **链接胶囊 & 图片缩略图条**：
   - 链接胶囊：高度 `26px`，背景 `--sp-accent`，文字 `--sp-accent-fg`，显示域名与路径摘要 + `×` 移除。
   - 图片缩略图条：横向 `flex-wrap: wrap`，间距 `8px`，每张为 `56×56px`、`border-radius: 8px`、`object-fit: cover`、`1px solid var(--sp-border)`；右上角悬停（或键盘聚焦）浮现 `18×18px` 深色半透圆形 `×` 删除按钮；左下角如超 1 张显示极小序号，末尾若达上限显示 `9/9`。
4. **`@项目` / `#标签` 行内联想浮层**：
   - 紧贴输入区下方内联展开（不溢出小面板窗口外），`max-height: 196px`，圆角 `10px`，背景 `--sp-surface`，边框 `1px solid var(--sp-border-strong)`，柔和投影。
   - 每行高度 `32px`，内边距 `0 10px`；项目项左侧带 `10×10px` 圆角 `3px` 项目纸胶带色块（`--sp-tape-1..6`），右侧显示状态说明；当前键盘选中行使用 `--sp-accent` 背景 + `--sp-accent-fg` 文字。
   - 已选项目在下方渲染为 `24px` 高纸胶带胶囊（对应 `--sp-tape-N` 背景与 `-fg` 文字，带 `×`）；已选标签渲染为 `24px` 高 `--sp-surface-muted` 圆角胶囊 `# 标签名 ×`。
5. **底部工具栏（`capture-toolbar`）**：
   - 高度 `44px`，顶边 `1px solid var(--sp-border)`，左右内边距 `12px 14px`。
   - 左侧工具按钮（`30×30px` 图标按钮或紧凑图文按钮，圆角 `8px`，静息透明、悬停 `--sp-surface-hover`，图标 `16px`，带 `title` Tooltip 与 `aria-label`）：
     - `截屏 / 选图`（相机图标，悬停提示「选区截屏 (⌥⇧4) · 右键或长按选本地图片」，并另备文件选择入口）
     - `选择项目`（文件夹/胶带图标，点击打开项目搜索浮层）
     - `补一句用途`（批注图标，点击切换展开/折叠用途输入框，已填写时呈 `--sp-accent` 高亮态）
     - 细竖分割线（`1px × 16px`，`--sp-border`）
     - `快找`（放大镜图标 + `⌘K` 小字，一键切至快搜视图）
   - 右侧提交区：
     - 仅当输入超过 `40,000` 字时显示字数警戒计数（`12px` `--sp-warning` / 超限 `--sp-danger`）；平时隐藏不制造噪音。
     - 主按钮 `收下`：高度 `30px`，内边距 `0 12px`，圆角 `8px`，背景 `--sp-primary`，文字 `--sp-on-primary`，右侧带半透键帽 `⌘↵`；内容为空时保持柔和禁用态（不降低全局对比度，改用 `--sp-surface-muted` 底 + `--sp-muted` 字）；写入本地期间（通常 <20ms）防重复提交。
6. **底部副条（极克制，按需显示）**：
   - 高度 `30px`（`padding: 0 14px`），字号 `12px`，背景 `--sp-surface-muted`（微透），与上方主卡以 `1px solid var(--sp-border)` 分隔。
   - 显示优先级（互斥，一次只展示最重要的一行）：
     1. **401 会话过期 / 暂停态**：红点 +「会话已失效，已安全暂停上传 · 点击重新登录」；
     2. **3 秒轻反悔态**（刚收下且面板被拉回时）：绿点 +「已收下（本机待同步 / 已同步）· 补项目或用途」；
     3. **需人工核对态**（`needs_review > 0`）：红/橙点 +「N 条记录需核对 · 查看原稿」；
     4. **离线待同步态**（`local_saved / syncing > 0`）：琥珀点 +「本机已收下，N 条待联网同步」；
     5. **菜单栏点击展开常态**：左侧折叠按钮「最近收下 (N) ▾」（展开最多显示最近 3 条单行卡片，标注「本机已收下」或「已同步」），右侧常驻低调文字按钮 `完整手帐 ⌘O`。
   - **拖拽覆层（Drag-over Overlay）**：当用户拖着图片/文件/链接悬停在面板上方时，面板内层铺一层 `2px dashed var(--sp-primary)` 虚线框 + 半透 `--sp-accent` 罩层，居中显示图标与「松手加入这条随手记（最多 9 张图）」。

### 3.3 同面板 `⌘K` 极速快搜视图（Quick Search Mode）

与悬浮随手记共享同一 `460px` 外框，切换无窗口跳动（`120ms` 淡切）。

```text
╭──────────────────── 460px ─────────────────────╮
│  [🔍] 搜索标题、正文、截图文字或项目…  [Esc 记一条]│  h=48px, border-bottom 1px
├────────────────────────────────────────────────┤
│  ▸ [🔗] 离线冲突处理方案参考        [Spark开发]  │  h=56px (当前选中: --sp-accent)
│    …本地队列采用原子落盘与幂等键重放…   2天前    │  高亮命中词: --sp-highlight-bg
│                                                │
│    [🖼] 筛选交互参考截图   [本机已收下]  刚刚    │  h=56px (未同步态微标)
│    参考这个移动端胶囊筛选交互                    │
│                                                │
│    [📝] SQLite WAL 配置备忘         [数据库学习] │  h=56px
│    synchronous=FULL 与 busy_timeout=5000        │
├────────────────────────────────────────────────┤
│  ↵ 打开/预览   ⌘C 复制即走   ⌘O 手帐详情        │  h=32px, bg: --sp-surface-muted
╰────────────────────────────────────────────────╯
```

- **搜索框**：高度 `48px`，左 `16px` 放大镜图标，输入框 `15px`，右侧轻胶囊 `Esc 返回记一条`。
- **结果行（`search-hit-row`）**：
  - 固定高度 `56px`，左右内边距 `14px`，圆角 `10px`（列表左右留 `6px` 边距，选中行不顶死窗口边缘）。
  - 第一行：左侧 `16px` 类型图标（文字/链接/图片；若图片有本地缓存缩略图则显示 `28×28px` 圆角 `6px` 小图）+ 加粗标题（`13.5px / 600`，单行省略）+ 右侧项目纸胶带微胶囊（最多 1 个，`height: 20px`）或同步状态微标（`本机已收下` 琥珀色 / `待核对` 红色；已同步不重复标绿标以减噪）。
  - 第二行：命中片段（`12px`，`--sp-muted`，关键词用 `<mark>` 标 `--sp-highlight-bg`）+ 右侧相对时间（`11.5px`）。
- **原位轻预览展开态**：按 `Space` 或点击预览图标时，面板平滑延展（最高 `520px`）在选中项下方展开完整纯文本摘要、原图缩略图与原链接，按 `⌘C` 复制、`Esc` 收回列表。
- **空态与无结果**：
  - 未输入时：默认列出「最近 6 条（本机待同步置顶 + 最近已同步）」，做到打开 `⌘K` 就能直接拿刚记的内容。
  - 无结果时：居中一行安静提示「没有找到与“关键词”相关的记录」（若当前离线，附一句「当前离线，仅搜索了本机已缓存的记录」），不铺大插画。

### 3.4 独立「灵光手帐」主窗口（Main Window）

用于低频深度阅读、按项目回看、检查待同步/需核对发件箱，以及管理外观与账号。

- **窗口尺寸**：初始 `1080×740`，最小 `820×560`；记忆上次关闭前的窗口位置与尺寸（外接显示器拔插后自动校验并回落至当前可见屏幕范围）。
- **一体式顶栏（`52px`）**：
  - 启用 macOS `MacTitleBarHiddenInset`（透明系统标题栏、隐藏窗口标题文字）。
  - 顶栏整条区域标记 `--wails-draggable: drag`，内部按钮与搜索框标记 `--wails-draggable: no-drag`。
  - 红黄绿按钮落在通顶侧栏的 52px 拖拽区，折叠按钮靠侧栏右缘。侧栏折叠后，主栏左侧留出 90px。
  - 顶栏右侧放搜索框与同步刷新按钮。仅在离线、待同步、需核对或会话到期时显示状态入口。
- **主工作区两栏骨架**：
  - **左侧栏（默认 `240px`，右边缘 `4px` 隐形拖拽条支持 `200px–300px` 调节，支持 `⌘\` 折叠）**：
    - 背景 `--sp-surface`（或轻半透纸面），右侧 `1px solid var(--sp-border)`。
    - 自上而下：顶部 `52px` 交通灯拖拽留白 → 品牌 `Spark`（小瓶子 + 圆体字标）→ 主色全宽「随手记」按钮（`height: 36px`，右侧 `⌥Space` 提示）→ 主导航「收件箱 / 全部收藏」（含「离线发件箱」入口，仅在存在待同步或需核对条目时高亮计数）→「项目」分组（进行中项目列表，每项左侧 `10×10px` 项目纸胶带色块 + 名称 + 收藏数）→「标签」分组（按计数排序）→ 底部固定区域：账号邮箱 + 30 天会话状态 + 外观设置（四套配色 × 明暗模式切换）。
  - **右侧主画布**：
    - 复用在线 Web 的点阵手帐纸背景（20px 点距，使用低对比度的主题边框色，背景固定不随滚动）。
    - 内容列居中 `max-width: 720px`，左右留白至少 `28px`。
    - **收件箱视图**：
      - 页头显示本地时段问候、日期与单行收集框。聚焦后展开输入区和工具栏，顶部 36×5px 灵光胶带使用当前配色的第二色。
      - 若当前账号有 `local_saved / syncing / auth_paused / needs_review` 发件箱记录，顶部先展示一张清晰区分状态的「本机发件箱」分组卡片（每条明确标注 **「本机已收下 · 待同步」**、**「同步中」**、**「会话失效 · 已暂停」** 或 **「需核对 · 原稿已保留」**，与下方云端已同步记录视觉分明）。
      - 下方按本地日期分组渲染云端已同步收藏：左侧吸顶撕页日期印章（今日主色顶条 + 圆体日期数字 + 星期），右侧纸条卡片（`14px` 圆角、`18px 22px` 内边距、最多 8 行正文、缩略图网格、项目纸胶带、标签胶囊）。
    - **收藏详情视图**：
      - 点击纸条卡片进入详情（保留顶部返回条、打开原网页、复制正文/链接、查看附件原图/缩略图、项目关联与 AI 摘要/图片说明展示）。
      - **一期边界提示**：遵循「不显示假功能」原则，凡后端一期桌面 Bearer 尚未开放的写操作（如在线编辑正文、修改归类、移入回收站、永久删除、AI 同意开关、管理员面板），不在桌面主窗口渲染可点击的假按钮，而是提供一个安静的「在网页版中编辑与整理 ↗」外链入口直达对应收藏页。

### 3.5 Spark 账号登录

首屏在本地窗口显示 Spark 标志、「登录 Spark」、带可见标签的邮箱和密码输入框，以及一个主按钮「登录」。表单跟随手帐主题，沿用系统字体、主色按钮和键盘焦点环。邮箱优先获得焦点，密码始终遮挡，Tab 依次访问两个输入框和登录按钮，Return 提交。窗口随错误提示增高。

表单采用单列纸卡，宽度上限 420px，内边距 24px × 26px，行间距 16px。输入框至少高 40px，聚焦时显示 3px 的 `--sp-focus-ring` 柔光。手帐窗口居中呈现表单卡片，随手记面板按表单高度调整。

提交期间控件禁用，按钮显示「正在登录…」。反馈显示在密码和主按钮之间；首次打开时不显示错误。失败后邮箱保留、密码框清空，可直接重新输入。会话过期时沿用同一表单，说明本机记录仍在；随手记中可返回原稿继续离线记录。

## 4. 动效、滚动与无障碍硬性规范

- **动效克制**：面板显隐 `160ms var(--sp-ease-out)`，视图切换 `120ms`；全面遵守 `@media (prefers-reduced-motion: reduce)`，开启减少动态效果时全部改为即时切换。
- **对比度与可读性**：所有常规正文与次要提示文字对比度 `≥ 4.5:1`，控件边框与滚动条滑块 `≥ 3:1`（深色模式滚动条默认 `rgba(255,255,255,0.36)`）。
- **可访问性**：全部图标按钮具备中文 `aria-label` 与 Tooltip；按钮通过外描边呈现键盘焦点，文字输入通过柔光或容器描边呈现焦点。侧栏分隔线可通过左右方向键调整宽度。
