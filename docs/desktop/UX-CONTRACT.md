# Spark macOS 桌面端交互契约

- **版本**：v0.8（新版 macOS 原生客户端交互定稿）
- **更新日期**：2026-11-22
- **状态**：设计基线。原生候选已完成收集、恢复、重放与撤销联调，逐项实测范围见 [桌面入口](README.md)
- **视觉参照**：[DESIGN.md](DESIGN.md)；架构与代码实现参照：[IMPLEMENTATION.md](IMPLEMENTATION.md)

本文定义 Spark macOS 桌面端所有用户可观察的交互行为、状态转换、快捷键规则、权限边界与异常恢复约定。实现时必须逐条满足，不私自增减假入口。

## 1. 窗口生命周期与注意力契约

| 场景 | 必须满足的行为 |
| --- | --- |
| 应用启动 | 默认以菜单栏常驻模式启动（`LSUIElement` / `NSApplicationActivationPolicyAccessory`），不占 Dock、不出现在 `⌘Tab`；仅首次未配对时弹出配对引导，已配对用户重启后静默就绪 |
| 单实例保护 | 重复打开 `Spark.app` 时不启动第二个进程，而是唤醒已有实例并打开主窗口（或聚焦配对视图） |
| 呼出悬浮随手记 | 无论用户处于普通桌面、分屏还是全屏应用，悬浮面板必须在**当前活跃屏幕与当前 Space 原地浮现**，绝不触发系统 Space 切换；呼出瞬间主输入框自动获得键盘焦点 |
| 关闭悬浮随手记 | 通过 `⌘↵` 保存、`Esc` 取消或点击面板外部空白收起面板时，隐藏面板并**将键盘焦点无损归还给呼出前的前台应用** |
| 打开独立主窗口 | 打开主窗口时将应用切换为 `Regular`（显示 Dock 图标与系统应用菜单），将窗口带到当前活跃 Space |
| 关闭独立主窗口（`⌘W` 或点击红灯） | 不退出进程；若主窗口处于全屏态，必须先退出全屏再隐藏（防止 macOS 留下空白黑屏 Space），随后卸载释放主窗口 `WKWebView` 并切回 `Accessory`（移出 Dock），保持极低常驻内存 |
| 退出应用（`⌘Q` 或菜单栏右键退出） | 若存在尚未完成写盘的捕获动作，先等待原子落盘完成再退出；已落盘的 `local_saved` 发件箱记录与暂存图片完整保留在磁盘，下次启动自动恢复同步 |

## 2. 快捷键全表与中文输入法（IME）防护

**上手原则**：首次使用只要求用户记住 **1 个核心主键 `⌥Space`**，其余快捷键均在面板界面中自然露出。

| 快捷键 | 作用域 | 行为 | 备注 |
| --- | --- | --- | --- |
| `⌥Space` | 全局（默认，支持设置中自定义） | 切换呼出/收起悬浮随手记；呼出时自动聚焦输入框 | 3 秒反悔窗口内再按可快速定位刚才收下的记录 |
| `⌥⇧4` | 全局（默认，支持自定义） | 直接发起原生选区截屏，截完自动带图弹回悬浮随手记 | 贴近系统 `⌘⇧4` 肌肉记忆 |
| `⌘↵` / `Ctrl+↵` | 随手记输入框聚焦时 | 提交收下：原子落盘成功即关闭面板并归还焦点 | 若正在 IME 组词（`isComposing`），先确认上屏不误提交 |
| `Tab` | 随手记输入框聚焦且剪贴板轻胶囊可见时 | 一键填入剪贴板建议内容（文字/链接/图片）并收起胶囊 | 胶囊不可见时保持正常焦点移动 |
| `⌘V` | 随手记面板 | 粘贴纯文本、URL 或剪贴板图片（自动识别类型并校验） | 多张图依次追加，最多 9 张 |
| `⌘K` | 悬浮面板内 / 主窗口内 | 悬浮面板内原地切换「快搜」与「随手记」；主窗口内聚焦搜索框 | 随手记输入框空态下首字符输入 `/` 也可切至快搜 |
| `↑` / `↓` | 联想浮层 / 快搜列表 | 移动选中高亮项 | `Enter` 确认选中的联想项或打开快搜结果 |
| `⌘C` | 快搜列表选中项时 | 将选中项的正文、原始链接或原图复制到系统剪贴板并轻提示「已复制」，可立即按 `Esc` 回原应用粘贴 | 实现“找到即带走，不必开大窗” |
| `Space` | 快搜列表（输入框非编辑光标状态或点预览钮） | 原位展开/收起选中项的轻预览 | 避免为了看一眼原文必须开主窗 |
| `⌘O` | 悬浮面板内 | 打开完整「灵光手帐」主窗口；快搜选中某条时直达该条详情 | 自动切入主窗口并显示 Dock |
| `Esc` | 悬浮面板（分层退出） | ① 若 `@`/`#` 联想浮层或轻预览打开 → 仅关浮层；② 若在 `⌘K` 快搜且有搜索词 → 清空搜索词，再按返回随手记；③ 在随手记 → 收起面板、保留未发草稿、归还焦点 | 绝不一次 `Esc` 清空用户输入 |
| `⌘\` | 主窗口 | 折叠 / 展开左侧边栏 | 折叠后顶栏内容自动避让红黄绿按钮 |
| `⌘W` | 主窗口 | 关闭主窗口退回菜单栏隐身 | 保留后台同步与全局快捷键 |

**中文输入法强制约定**：所有基于 `Enter`、`Escape`、`Tab`、`@`、`#` 的快捷键与联想触发，必须判断 `!event.isComposing && event.keyCode !== 229`，杜绝在拼音/五笔候选词确认瞬间误提交或误关面板。

## 3. 四大高频收集交互细则

### 3.1 剪贴板 20 秒轻建议胶囊
1. **启动基线忽略**：应用启动时只记录当前 `NSPasteboard.changeCount`，不把启动前已留在剪贴板的旧内容当作新复制弹出。
2. **20 秒新鲜窗口**：仅当剪贴板在最近 `20 秒` 内发生过变更，且包含非空文字、HTTP(S) 链接或合法图片（≤ 5 MiB）时，呼出随手记面板才在输入框下方显示轻建议胶囊。
3. **不强行塞入输入框**：胶囊仅作为手边建议；用户按 `Tab` 或点击胶囊时才填入当前草稿（文字/链接写入正文并提取 URL，图片加入附件缩略图条），随后胶囊消失；用户如果直接开始打字或点击 `×`，胶囊立即静默消隐。
4. **隐私绝对红线**：
   - 仅保留内存中的最新一条采样，**严禁落盘、严禁上传、严禁建立剪贴板历史库**；
   - 检测到系统剪贴板包含 `org.nspasteboard.ConcealedType`、`org.nspasteboard.AutoGeneratedType`、`org.nspasteboard.TransientType` 或密码管理器标记类型时，**立刻清空现有建议且绝不展示**；
   - 剪贴板图片仅在用户明确点击/按 `Tab` 填入并按 `⌘↵` 收下后，才进入发件箱与云端上传。

### 3.2 原生选区截屏即收
1. **触发**：按下全局 `⌥⇧4` 或点击随手记工具栏相机图标。
2. **执行**：若悬浮面板当前打开，先临时隐藏面板避免把自己截进画面；调用系统原生选区截屏（`/usr/sbin/screencapture -i -x -t png <临时文件>`）。
3. **结果处理**：
   - 用户框选完成：校验 PNG 魔数与 `≤ 5 MiB` 限制后，立即删除临时文件，把图片挂入随手记草稿缩略图条，原地拉起悬浮面板并聚焦输入框，用户可顺手补一句用途或直接 `⌘↵` 收下。
   - 用户按 `Esc` 取消截屏：无报错、无残留文件；若原本从面板内触发则平滑恢复面板。
   - 权限不足（macOS 屏幕录制未授权）：仅在此时温和提示「需要开启系统“屏幕录制”权限才能使用选区截屏」，提供「前往系统设置」按钮；其余收集能力不受影响。

### 3.3 拖拽关联（菜单栏小瓶子 + 面板）
1. **拖到菜单栏小瓶子**：
   - 支持拖入：图片文件（JPG/PNG/GIF/WebP）、多张图片（≤ 9 张）、网页链接（URL）、选中文本。
   - **直接松手**：不弹窗打断用户，直接校验并原子写入当前账号发件箱（自动识别 URL/图片/文字），菜单栏小瓶子轻闪 `450ms` 反馈「已收下」。若遇不支持的文件格式或超过 5 MiB/9 张，弹出轻量错误气泡说明原因，不静默丢弃。
   - **悬停 `0.4 秒` 不松手**：自动展开悬浮随手记面板，用户把内容拖入面板松手后即可补写用途或选项目再收下。
2. **拖到已打开的随手记面板**：
   - 拖入时展示虚线接纳罩层，松手将图片追加至缩略图条（或把链接/文字插入输入区），支持连续多次拖入直至 9 张上限。

### 3.4 同面板 `⌘K` 极速快搜
1. **零延迟首屏**：切换到快搜视图时，未输入关键词即先展示最近 6 条（本机未同步条目置顶 + 本地缓存最新条目）。
2. **本地秒搜 + 联网补齐**：
   - 输入关键词后 `0ms` 立即检索本地 SQLite（覆盖发件箱原稿 + 已缓存收藏的标题、正文、用途、网址、项目、标签）；
   - 若在线且已配对，经 `180ms` 防抖后并发请求 `GET /api/v1/search`，将云端结果（含服务端提取的网页正文、截图 OCR 文字与 AI 画面描述）按 ID 去重合并展示，保持键盘高亮焦点不跳乱；
   - 离线时只展示本地命中结果，底部安静注明「离线模式 · 仅搜索本机缓存」。
3. **找到即用**：`⌘C` 直接复制内容到剪贴板；`Enter` 打开原网页或展开原位轻预览；`⌘O` 打开主窗口直达详情。

## 4. 自动识别、草稿保护与 3 秒反悔

- **自动识别内容类型**：无手动类型切换 Tab。输入内容中自动提取首个合法 HTTP(S) 网址作为 `original_url`（用户可点胶囊 `×` 取消关联）；带图片自动按含图收藏处理；正文 + 用途合计上限 `50,000` 字，单图 `≤ 5 MiB`，单条最多 `9` 张图。
- **`@项目` 与 `#标签` 联想**：
  - 输入 `@` 触发本地缓存的进行中项目联想，选中后加入 `project_ids` 并显示项目纸胶带胶囊（可删）；
  - 输入 `#` 触发本地缓存的已有标签联想，选中后加入 `tag_ids` 并显示标签胶囊（一期桌面 Bearer 不直接新建标签，无匹配时保留原文 `#词` 交由云端整理或后续网页补建）。
- **未发草稿自动保留**：收起悬浮面板（`Esc` 或失焦）不丢失已输入的文字、用途、已选项目和暂存图片，下次呼出继续编辑；仅在按 `⌘↵` 成功原子落盘后清空当前草稿。
- **3 秒轻反悔**：`⌘↵` 收下后面板立即消失不打扰；若 `3 秒` 内再次按 `⌥Space`，底部副条轻提示刚才收下的条目状态，方便用户一键查看或跳进主窗口补充。

## 5. 本地已收下、已同步与异常态契约

界面必须**明确区分「本机已收下」与「已同步」**，绝不把离线暂存伪装成已上云，也绝不因断网阻断记录：

| 状态 | 触发条件 | 用户可见反馈与可执行操作 |
| --- | --- | --- |
| **本机已收下**（`local_saved`） | `⌘↵` 已完成原子落盘（SQLite 事务 + 图片文件 `fsync`），尚未上云或当前离线 | 悬浮面板立即收起不阻断；菜单栏微点提示；主窗口与最近列表标注「本机已收下 · 待同步」；联网后自动静默上传 |
| **同步中**（`syncing`） | 正在上传 OSS / 轮询 `complete` / 提交 `POST /collections` | 标注「同步中…」，不可重复手工派发新 ID |
| **已同步**（`synced`） | 服务端返回 `201`（含同键重放）或核对 `GET /collections/{id}` 确认存在 | 清理本地暂存原图副本，合入本地读缓存，状态转为「已同步」 |
| **会话失效 · 已暂停**（`auth_paused`） | 任一请求返回 `401 desktop_session_expired` 或本地判断 30 天已到期 | **立即停止队列全部后续上传**；保留本机全部待发原稿与图片；底部副条与主窗口清晰提示「重新配对」，原账号重绑后自动恢复上传 |
| **需人工核对**（`needs_review`） | 遇到 `409 duplicate_resource`/墓碑、超 7 天已发未知经 `GET` 仍为 `404`/无法确认、`413`/`422`/`upload_rejected` | **绝不自动更换 UUID、绝不覆盖、绝不复活已删记录**；完整保留本地文字与图片原稿，在主窗口「本机发件箱」展示明确原因、原 ID（方便去网页核对）及用户手动「复制原稿 / 删除本地稿」按钮 |

### 账号切换与断开设备契约
- **严格账号隔离**：发件箱与读缓存均按 `account_id` 隔离。若用户断开账号 A 并配对账号 B，账号 A 留在本地的未同步或待核对记录**原地封存，绝不向账号 B 发送、绝不在账号 B 列表或 `⌘K` 中可见**；切回账号 A 后重新可见并继续。
- **断开前提醒**：用户点击「断开此设备」时，若当前账号仍有未同步的 `local_saved / syncing / needs_review` 条目，先弹出明确确认框告知数量，说明「断开后会安全保留在本机，但需重新登录此账号才会继续同步」。
- **未配对态限制**：未配对账号时不支持直接写进无归属发件箱，呼出随手记直接引导进入配对卡片（避免产生无账号归属的孤儿数据）。

## 6. 二期交互规划（本轮明确不做，预留扩展点）

以下能力已评估但不在 v0.8 首批交付范围内，避免一期摊子过大：
- 拖动文件至屏幕边缘自动滑出的侧边轻口袋；
- 监听系统 `⌘⇧4` 桌面截图目录及收完自动清桌面原图；
- 零弹窗静默快收剪贴板与浏览器当前页出处自动附带；
- macOS 系统右键「服务 / 分享扩展」与自动更新器；
- 桌面端内直接在线编辑正文、手动改归类、移入回收站及 SSE 实时推送（需待后端后续批次扩展桌面 Bearer 范围与开放 `/api/v1/organization/events` 后再接入）。
