## 2026-11-25 Web 侧栏减负（候选）

- 搜索入口合并：侧栏「记一条」下方为形似输入框的「搜索或跳转」（⌘/Ctrl+K）；页头搜索框只保留在全部收藏页，用于就地筛选。
- 导航显示数量：收件箱「N 未读」、待归类条数；项目行显示收藏数。列表接口没有总数，侧栏各读一页 20 条，超过显示「20+」。这让收件箱首次加载多一个小请求，原「收件箱不额外请求待归类」的测试改为只允许这一页。
- 项目区只留一个「+」直接新建，「自定义」在指向时出现；标签可折叠，其余标签用「+N」打开搜索。
- 灵光日历从侧栏移到收件箱页头按钮，手机与桌面同一入口。
- 侧栏底部压成一行：账号名、回收站、设置；鼠标设备上行距收紧，笔记本屏幕也能看到标签。
- 验证：`npm run typecheck`、`npm run build` 通过；`vitest`（4 个 worker）221 项全部通过（已同步 main v0.11.1）；在测试适配器预览中检查了 1100×760、360px 与导航抽屉。

## 2026-11-25 v0.11.0 回收站彻底清除与主题修复（候选）

## 2026-11-24 Web 交互与动效打磨（候选）

- 统一动效语言：新增位移曲线 `--sp-ease-move`，常规 / 面板时长调整为 240 / 320ms，全站硬编码时长改用令牌。列表增删时卡片滑到新位置；分段控件用滑动底块；进入详情向左推入、返回向右退回；菜单与底部面板有退出动画；切换配色或明暗时整页交叉淡入。全部遵守减少动态效果设置。
- 减少用户要做的判断：空收件箱不显示筛选条；少于 3 条未归类时不提示进入整理模式；没有待确认建议时隐藏待归类的视图切换；「整理排队中 / 正在整理」统一为「整理中」。
- 能替人做的直接做：图片上传中也可以按保存，传完自动提交；分页列表滚动到底自动加载。
- 反馈与防误触：发送按钮显示保存中和保存成功；收件箱内联保存不再弹提示条；提示条悬停时暂停；移入回收站立即有反馈并关闭菜单；详情操作按频率重排，移入回收站弱化并与其他操作隔开；回收站的永久删除改为弱化的危险文字按钮。
- 从列表打开详情时，导航高亮保留在来源页。
- 安卓端在 `feat/android-v0.3-foundation` 线上同步动效令牌（无本地安卓环境，未构建）。
- 验证：`npm run typecheck`、`npm run build` 通过；`vitest`（4 个 worker）212 项全部通过，默认并发下有 2 项因负载偶发超时，单独运行通过；在测试适配器预览中检查了 360px、桌面宽屏与深色模式。

## 2026-11-24 v0.10.0 项目删除与附件清理（候选）

- 可在 Web 项目详情删除本人项目。收藏、其他项目归属和图片保留；删除后项目从项目列表消失。
- 笔记移入回收站后可恢复；启用永久删除后，可以在回收站确认提前清理。清理进度由服务端回执确定，附件对象删除成功后才显示完成。
- 首次启用自动清理时，发布参数固定到期处理的起点。此前已经逾期的回收站内容仍可手动处理。
- 支持将永久删除回执写入 OSS 的专用私有前缀。恢复旧数据库时可从该前缀重放删除决定。

## 2026-11-22 v0.8.1 网页笔记整理失败后可重试（候选）

- 上一次网页整理已计入用量却没有可用结果时，符合条件的笔记在详情里提供「重试网页归类」。确认前会说明本次使用 AI 额度。刷新或重复提交同一确认只查询或复用同一个任务。
- 网页归类要求模型精简输出。供应商明确报告输出被截断时，详情显示具体原因；旧版未记录的停止原因继续按原错误展示。

- 桌面设备可通过浏览器核对账号和配对码，获得 30 天有效的独立会话。在设置中撤销一台 Mac，其他已登录的浏览器和扩展继续使用。
- 服务端和 Web 已通过隔离升级、配对与撤销联验。原生客户端交付范围见 [v0.8 计划](releases/v0.8.md)。

## v0.7.3 网页自动归类与收藏详情（候选）

- 网页标题或选文中有明确主题、整理结果也提取出相应标签时，Spark 可以直接归入已有项目或建立短主题项目。手选项目优先。证据不足或存在同等可信的不同主题时，收藏保留在待归类。
- 收藏详情把项目归属放在一起。归好后点项目名即可打开项目；需要操作时显示原因和下一步。调整项目、暂停整理等操作收在「更多管理与整理详情」中。
- 打开符合条件的已分析网页，Spark 会用已结算的结果自动补归类，保留已有人工决定，无需重新调用模型。现有浏览器扩展继续可用。

## v0.7.2 网页收藏保存反馈与归档（已上线）

- 在扩展长表单底部保存后，弹窗直接显示收藏标题和「在 Spark 中查看」。只有点击「继续收集」才重新打开表单。手动加载过 v0.7.1 的用户，发布后可用新版文件替换原扩展目录内容，再在浏览器扩展管理页点重新加载。
- 在 Spark 更新文字整理授权后，新保存的网页可根据标题、选文和用途归入项目。手选项目优先。旧收藏可在详情里单独发起网页归类；只有网址时，先补充标题或用途即可。
- 若任务排队过期且没有用量记录，详情页支持手动重试。保存响应丢失时，扩展使用原请求核对，避免重复创建。

## v0.7.1 浏览器收集助手（已上线）

- 在网页上打开扩展，或右键收藏选文，可核对标题、网址、选中文字和用途，再选择项目保存。
- 扩展首次使用时需要在 Spark 中确认配对。可以在设置里单独撤销设备；发送结果未知时，可用同一账号恢复待提交记录并核对保存结果。

## v0.7.0 笔记续写（已上线）

- 从收藏卡片或详情点「续写」，即可把新进展保存为独立笔记。项目可沿用、调整或清空，输入草稿按账号和来源分别保存。
- 打开线索中任意一条活跃笔记即可按时间回看。删除中间一条时显示占位，恢复后可以重新打开。分页暂时失败时保留已加载的内容。

- 修复项目页收集框第一次点「×」只展开输入框的问题。移除默认项目后，即使还没写正文，刷新仍保留这项选择。

## v0.6.5 简短项目名与自动打标（已上线）

- 自动新建项目优先采用可复用的短主题。具体工具、方法和概念以标签保留，可按标签找回笔记。
- 在设置中更新文字整理授权后，可从笔记内容生成最多 3 个标签并自动添加。旧授权继续按原有范围整理。

## v0.6.4 图片笔记（已上线）

- 图片识别返回部分内容时显示「图片摘录」。已有画面描述可在正文中查看、修改或移除，搜索、分享卡片与导出使用当前保存的说明。
- 开启新版自动归类后，图片笔记可直接归入已有项目，也可根据识别出的明确主题新建项目。保留人工归属和忽略操作。已有笔记可在详情重新整理，复用原有识别结果。
- 生成分享卡片时默认包括图片缩略图，可以逐张取消；预览和下载共用同一份 PNG。

## v0.6.3 图片识别结果兼容修复（已上线）

- 图片模型只返回文字或画面描述、或同时附带说明字段时，详情保留有效的识别内容。额外字段不进入搜索和项目建议。
- 旧版首次识别或重新识别后，如果费用已结算但 Spark 因响应格式丢失结果，可从原收藏确认重新识别。费用不明的请求继续保留原记录。详情区分模型未返回内容、响应内容格式不符和用量待核对等情况。

## v0.6.2 密集图片识别（已上线）

- 图片理解先生成简短画面描述，再摘录标题和关键原文。达到输出上限时，详情保留可用摘录；如果没有完整摘录，会说明截断原因。
- 旧图也可在详情中单独确认重新识别。额度在派发前耗尽时，可以在额度恢复后重排同一任务。原图、既有记录和历史用量均保留。

## v0.6.1 图片整理与草稿保护（已上线）

- 有图片试用资格的账号可以授权将已识别的图中文字和画面描述用于项目建议。新收藏等待图片识别；旧收藏可在详情页重新整理，复用有效识别结果。项目建议显示图片依据，由用户确认。
- 编辑草稿遇到其他设备更新时可以比较并保留两份内容。随手记可以找回已就绪的图片，退出结果未确认时保留账号草稿。
- 收件箱、全部收藏、项目资料均可按图片筛选。返回项目后保留筛选与搜索，待确认的卡片随实时通知更新。
- 验证范围与各项修复的状态见[版本记录](releases/v0.6.md#7-v061-线上功能完整性修复)。

## v0.6.0 表达与效率

## 2026-11-19 v0.3 发布与数据库回退

- 发布脚本支持附件、网页提取、图片理解和永久删除的部署配置，跨版本迁移需要显式开启。新服务可能已接受写入时保留活库；存在删除记录时转入离线恢复和重放。已在独立 OrbStack 栈完成合成数据演练。
- 跨版本自动还原须由目标端确认迁移在启动服务前失败，并核对仅 PostgreSQL 运行。发布进入可能写入阶段，或迁移结果未经确认时，退出码 `2` 表示保留现库，需运维处置。
- 发布回退以快照和当前环境文件共同决定 API 开关、叠加配置和 Worker。能力冲突时保留停用状态并逐项报告，手动回退以状态码 `3` 标明能力差异。
