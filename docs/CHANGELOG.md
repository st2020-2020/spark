## 2026-11-19 v0.2.1 生产 Worker 重启恢复

- Docker 重启后，已启用并运行的 AI Worker 会自动恢复处理队列。运维主动停止的 Worker 保持停用，直到显式启动。

## 2026-11-19 v0.2.0 整理与信任

- 待归类页可逐条加入项目、跳过并撤销最近一步；恢复已确认的 AI 建议时保留原引文。与其他操作发生版本冲突时保留最新决定。

- 管理员用户列表支持只读分页。生产发布从已评审的版本标签构建，验证与上线路径见 [ROADMAP](ROADMAP.md) 和 [部署说明](../deploy/README.md)。

## 2026-11-18 Web 视觉重构「灵光手帐」

### 新增
- 小瓶子标志、favicon 与三幅随配色变化的插画。
- 四套主题配色（薄荷晨雾、海盐蓝、抹茶奶白、樱花雾粉），各含深色版本；配色与明暗可在设置页独立切换。
- 收件箱按天分组的日志与日期印章；纸条式卡片；项目纸胶带色。
- 随手记：任意页面弹出快速收集面板，桌面快捷键 N。
- 手机悬浮导航坞与底部面板（更多导航、卡片操作、弹窗）。

### 变更
- 登录、注册、重置改为双栏布局；加载改为骨架屏；空状态配插画。

### 验证
- 前端类型检查、生产构建、22 项行为测试通过；测试适配器预览已检查四套配色、深浅色与手机宽度。尚未在 OrbStack 真实后端联调复验。接口与业务行为未变。
