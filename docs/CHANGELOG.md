# 变更记录

按日期记录已交付的迭代变更，新条目写在最上方。每条写清做了什么、影响范围和验证状态；详细验证证据见 [ROADMAP.md](ROADMAP.md)，取舍理由见 [DECISIONS.md](DECISIONS.md)。

格式：`## YYYY-MM-DD 标题`，下列「新增 / 变更 / 文档 / 验证」中适用的小节。

## v0.6.0 表达与效率（候选）

- 输入 `#` 可选择或新建个人标签，输入 `@` 可选项目。侧栏按标签找回收藏，导出保留标签与人工决定。
- 收藏详情可在本地生成 PNG 分享卡片。来源和项目默认隐藏，预览后可下载，支持文件分享的浏览器可调用系统分享。
- 列表支持键盘导航，命令面板可搜索收藏、跳转项目、切换外观。登录后配色与明暗偏好随账号保存。
- 在设置中确认新版整理说明后，文字 AI 可使用与材料匹配的已有标签。旧授权继续原有文字整理，图片分析沿用 v0.5.1 的独立管理员试用范围。

## v0.5.1 管理员图片试用

- 图片理解可限定为指定的在任管理员。需要单独授权，继续使用平台与账号的共享预算。
- 更新设置页的可用状态说明；失去试用资格后仍可撤回图片授权。

## v0.5.0 回访与时间（候选）

- 收件箱的「今日重现」每天最多展示三条自己的旧收藏，可打开、归类或在当天隐藏，也可在设置中关闭。
- 桌面侧栏和手机「更多」提供灵光日历，按当地日期显示收藏数；点击某天可筛选收件箱。
- 数据库迁移至 v9。使用详情入口时单独记录最近主动打开时间。隔离栈和浏览器验证见 [ROADMAP](ROADMAP.md#v05-回访与时间)。

## 2026-11-20 管理后台表单修复

- 邀请码 CSV 选择按钮和空状态改用中文。键盘可打开文件选择器，读屏可获取文件名；取消后保留内容，重选同一文件可重新读取。
- 预算保存按钮与输入框等高并对齐底边，窄屏可换行。已通过 Web 回归和隔离浏览器验证，详见 [ROADMAP](ROADMAP.md#管理后台表单修复2026-11-20)。

## v0.4.0 邀请注册与密码找回

- 独立邮件 Worker 支持腾讯云 SES 模板 API 和 SMTP。注册与重置的六位验证码分别绑定邮箱和用途。验证码有效期 10 分钟，重发后替换上一次验证码。隔离环境已用受控邮箱完成浏览器注册和密码重置。
- 数据库显式升级到 v8。加密备份在隔离环境验证过恢复后撤销旧会话、作废验证码及取消旧邮件任务。生产异机备份需要另行配置存储和密钥保管。
- 新版 Android 客户端可从网页的「更多」打开本机草稿。普通浏览器继续使用网页导航。
- 更新后端 Go 工具链和依赖以处理安全公告。隔离数据库回归通过，OpenAPI 生成结果一致。

## v0.3.0 收集与附件

- 支持收集、预览和找回图片。附件使用账号隔离的私有存储和短时授权。
- 网页正文提取、独立授权的图片理解、永久删除与回执重放分别由可选 Worker 提供。各能力的生产启用状态以实际发布记录为准。
- 数据库显式迁移至 v7。升级和回退已通过隔离演练。

## 2026-11-19 v0.3 图片存储授权上限

- 新上传按账号限制数量和声明大小，同时单独限制上传、下载签名次数。原键补签复用待上传记录，超限响应带等待时间。

## 2026-11-19 v0.3 真实 OSS 隔离验收

- 合成图通过隔离 Origin 直传、资产 Worker 校验、保存及字节一致的下载。当前角色删除测试键时返回 403，两个未清理对象已在演练记录中登记。

## 2026-11-19 v0.3 schema v7 发布演练

- 发布脚本在预检和切换中使用候选提交声明的同一目标版本。默认关闭外部能力时，隔离演练已验证 v3 升至 v7、上传清理重入命令和显式回退到 v3。

## 2026-11-19 v0.3 后端审查修正

- 含对象的删除回执在恢复库缺账号时明确中止。图片理解使用应用方向、剥离元数据的副本。
- 长主网址使用有界去重索引。上传清理可有界重入耗尽重试的任务，并保留已绑定原图。

## 2026-11-19 v0.3 图片授权

- 平台暂停图片理解时，设置页仍可撤回已有授权。仅在服务端所需版本与页面实际展示的说明一致时开放授权。

## 2026-11-19 v0.3 图片收藏幂等回放

- 图片存储关闭后，已保存的含图收藏仍可用原请求重放创建响应。新的含图写入继续受开关限制，永久删除墓碑仍阻止旧请求使收藏复活。

## 2026-11-19 v0.3 发布与数据库回退

- 发布脚本支持附件、网页提取、图片理解和永久删除的部署配置，跨版本迁移需要显式开启。新服务可能已接受写入时保留活库；存在删除记录时转入离线恢复和重放。已在独立 OrbStack 栈完成合成数据演练。
- 跨版本自动还原须由目标端确认迁移在启动服务前失败，并核对仅 PostgreSQL 运行。发布进入可能写入阶段，或迁移结果未经确认时，退出码 `2` 表示保留现库，需运维处置。
- 发布回退以快照和当前环境文件共同决定 API 开关、叠加配置和 Worker。能力冲突时保留停用状态并逐项报告，手动回退以状态码 `3` 标明能力差异。

## 2026-11-19 v0.3-T05 图片理解 Web 联调

- 用户可在设置中单独授权图片理解，在收藏详情查看图中文字和画面描述，并用两类内容搜索。额度不足或撤回授权后仍可查看原图。隔离浏览器已验证授权、预算与单条排除的调用次数。

## 2026-11-19 v0.3-T05 图片理解后端

- 新增独立图片授权、按图调用 DeepSeek Flash 与共享日预算。图中文字、AI 画面描述分别返回和检索，截断时显式标记。
- 已发送而缺少可靠计量的请求保留待核对额度。永久删除清除图片派生数据并保留账务。

## 2026-11-19 v0.3-T08 永久删除与恢复

- 新增永久删除和清理状态 API、30 天到期任务、独立删除回执与恢复重放。完成清理后保留墓碑，模型用量账务可继续结算或对账。
- 收藏列表与搜索返回当前封面、附件数和链接预览，供 T07 消费。

## 2026-11-19 v0.3-T06 网页信息提取

- 新增异步网页标题、站点与摘要提取，以及重新获取和网页正文检索。提取有独立开关，失败时收藏继续保留原网址。受控页面验证了内容编辑后旧结果丢弃。

## 2026-11-19 v0.3-T03 图片上传与下载授权

- 新增图片直传、异步校验、收藏绑定和短时下载授权。资产 Worker 独立执行校验及到期清理，启用 OSS 时文字 AI 和 OCR 可保持关闭。隔离浏览器已验证纯图片收藏保存、整页刷新及跨账号访问控制。

## 2026-11-19 v0.3-T02 附件与提取数据层

- 新增数据库迁移 004 及上传、附件、提取结果与删除账本的数据访问层。隔离 PostgreSQL 验证了 v3 数据保留、跨账号约束、单次绑定、历史引用与删除重试。上传接口、对象清理和提取任务由 v0.3 后续批次接入。

## 2026-11-19 v0.2.1 生产 Worker 重启恢复

- Docker 重启后，已启用并运行的 AI Worker 会自动恢复处理队列。运维主动停止的 Worker 保持停用，直到显式启动。
