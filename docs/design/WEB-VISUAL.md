## 1. 设计概念

**灵光手帐**：先把一闪而过的念头装进瓶子，再慢慢整理到项目里。界面像一本点阵手帐：每天的收藏按日期排成日志，每条收藏是一张纸条，项目用不同颜色的纸胶带标出。

设计原则：

1. **收集先于整理，原文先于元数据。** 进入页面就能写；保存后连续阅读；想整理时再选项目。
2. **一处大胆，其余克制。** 个性集中在点阵纸、日期印章、纸胶带与小瓶子上，控件、间距、文字保持安静一致。
3. **颜色有含义。** 主色表示操作与当前位置；第二色只用于「灵光」相关的提示（待确认、AI 建议、刚保存）；项目色只标识项目。
4. **不显示假功能。** 未接通的能力不出现可点击入口。
5. **手机与电脑同等用心。** 手机不是缩小版桌面，有自己的导航、面板与触控尺寸。

## 2. 品牌与插画

- **标志**：主色圆角方块内的小玻璃瓶，瓶中一颗第二色的灵光（`components/Brand.tsx` 的 `JarGlyph` / `BrandMark`）。同一图形用作 favicon（薄荷主色版）。
- **字标**：「Spark」使用圆体（`--sp-font-round`：系统圆体，无则回退界面无衬线）。
- **插画**（`components/Illustrations.tsx`）：瓶子、笔记本、放大镜三幅扁平线稿，颜色全部取自当前配色令牌，装饰性、对读屏隐藏。
  - 瓶子：收件箱空态、全部收藏空态、登录页。
  - 笔记本：项目列表空态。
  - 放大镜：筛选或搜索无结果。
- **动效**：全站唯一的常驻动效是登录页「灵光飘向瓶子」；减少动效偏好下静止显示。

## 3. 外观：配色 × 明暗

`src/styles/tokens.css` 是唯一令牌入口。外观由两项独立选择组成，均由 `src/lib/appearance.ts` 写入 `<html>`。登录时使用当前账号的偏好，未登录时读取本机的 `spark:palette` 与 `spark:theme`：

- `data-palette`：主题配色，默认 `mint`。
- `data-mode`：明暗，由「跟随系统 / 浅色 / 深色」解析；跟随系统时监听系统切换。

首屏渲染前即应用外观，避免闪烁；浏览器 `theme-color` 随当前背景色更新。设置页「界面外观」提供配色卡片与明暗分段控件。

| 配色 | `--sp-primary` 浅 / 深 | `--sp-accent` 浅 | `--sp-spark`（第二色）浅 | `--sp-bg` 浅 / 深 |
| --- | --- | --- | --- | --- |
| 薄荷晨雾 `mint`（默认） | `#2a8369` / `#6fd1b2` | `#e0f2eb` | 蜜桃 `#ffd9c7` | `#f2f8f6` / `#0f1715` |
| 海盐蓝 `sea` | `#3274aa` / `#8cc0ec` | `#e2eef8` | 柠檬 `#fff1a6` | `#f1f6fa` / `#0f141a` |
| 抹茶奶白 `matcha` | `#557f45` / `#a6cc8f` | `#e9f0df` | 奶油米 `#f3e3c3` | `#f6f7f1` / `#12140f` |
| 樱花雾粉 `sakura` | `#ae5468` / `#f0a3b4` | `#fbe6ea` | 薄荷 `#cfe6de` | `#fbf6f6` / `#171213` |

令牌职责：

| 令牌 | 用途 | 约束 |
| --- | --- | --- |
| `--sp-primary` / `--sp-on-primary` | 主操作、链接、焦点、品牌标记、「记一条」 | 浅色下与白字对比 ≥ 4.5:1 |
| `--sp-accent` / `--sp-accent-fg` | 当前导航、选中、格式激活、空项目图块 | — |
| `--sp-spark` 系列 | 待确认徽标、AI 建议、刚保存光晕、收集框胶带 | 文字配 `--sp-on-spark` |
| `--sp-tape-1..6`（含 `-fg`） | 项目纸胶带色，各配色共用，深色另有一组 | 胶带文字与底色对比 ≥ 4.5:1 |
| `--sp-muted` | 时间、说明 | 白底 ≥ 4.5:1 |
| `--sp-control-border` | 输入框边界 | ≥ 3:1 |
| `--sp-highlight-bg` | 搜索命中与正文高亮 | 文字用前景色 |
| `--sp-success` / `--sp-danger` / `--sp-warning` | 状态色 | 各配色共用 |

新增配色时须完整定义浅、深两组同名颜色令牌，并在 `PALETTES` 中登记名称、说明与色样。

## 4. 排版、间距与形状

- **字体**：界面无衬线 `--sp-font-sans`（-apple-system、PingFang SC、HarmonyOS Sans SC、MiSans、Microsoft YaHei UI、Segoe UI、Noto Sans CJK SC 等）；字标、页标题、日期印章数字用圆体 `--sp-font-round`。国内访问不引入远程字体。
- **字号阶梯**：12 / 13 / 14 / 15 / 16 / 18 / 22 / 26px。正文与编辑器 16px / 1.75；详情正文 17px / 1.8；控件 14px；时间与说明 13px；页标题桌面 26px、手机 28px（圆体 750）；卡片自定义标题 18px / 650。
- **间距**：4 / 8 / 12 / 16 / 24 / 32 / 48px。卡片内边距桌面 18px 22px、手机 14px 16px；卡片间距 12px（手机 10px）；日志分组间距 30px（手机 24px）。
- **圆角按层级**：登录对折纸 30px；侧栏纸面板 24px；收集框 22px（手机 18px）、弹窗与底部面板 20–22px；纸条卡片 18px（手机 16px）；按钮与输入 10–12px；筛选与标签为胶囊形。圆角相互嵌套时，内层圆角 = 外层圆角 − 边框宽度（例如收集框底部的 AI 入口条）。
- **画布**：页面背景为点阵手帐纸（22px 点距，前景色 11% 透明度，背景固定不随滚动）。
- **阴影**：只用柔和、带少量环境色的投影；卡片仅在可悬停设备上加深阴影，不位移。
- **焦点与状态**：焦点 2px 主色描边 + 2px 偏移，输入框聚焦另加 3px 主色光晕；错误同时有文字；禁用不靠整体降低透明度表达。
- **动效**：见 [4.1 动效语言](#41-动效语言)。

### 4.1 动效语言

动效只用来交代状态变化：东西从哪来、到哪去、和什么有关。同一类变化全站使用同一组令牌（`tokens.css`），不在组件里另写时长或曲线。

| 变化 | 曲线 | 时长 |
| --- | --- | --- |
| 出现、淡入、按下回弹 | `--sp-ease-out` | `--sp-dur-fast` 160ms |
| 位置变化（列表让位、分段指示条滑动、页面推入 / 返回） | `--sp-ease-move` | `--sp-dur-normal` 240ms |
| 原地弹出的小元素（勾、计数、图标切换） | `--sp-ease-spring`（回弹 < 2%） | `--sp-dur-fast` |
| 底部面板、抽屉 | `--sp-ease-sheet` | `--sp-dur-sheet` 320ms |
| 退出（菜单、弹窗、提示条离开） | `--sp-ease-exit` | 比进入短，约 140–240ms |

- **按下**：按钮、筛选胶囊、分段按钮、菜单按钮按下时缩到 `--sp-press-scale`（0.97），松开回弹；只改 `transform`。
- **列表**：收件箱、全部收藏、待归类、回收站与提示条堆叠使用 FLIP（`useFlipList`）：新卡片从上方轻落，其余卡片滑到新位置；视口外的卡片和超过一屏的位移直接跳过。移入回收站时卡片立即变淡缩小，邻居随后让位。
- **分段控件**：「全部 / 未读」、项目状态、主题明暗、导出格式等分段控件共用滑动底块（`useSegmentIndicator`），选中项字重不变，避免换行抖动。
- **页面**：进入更深一层（如列表 → 收藏详情）向左推入，返回向右退回，同层切换只淡入。
- **浮层**：菜单、底部面板和遮罩都有退出动画（`usePresence`），退出期间不可交互；再次打开会从当前状态接上。手机端底部面板与抽屉可从抓手区域下拉跟手关闭，未达阈值回弹。
- **换内容**：发送按钮在「保存 → 保存中 → 已保存（勾，约 1.2 秒）」之间交叉切换图标；已读状态图标、导航计数同样原位切换。整理中状态用一个缓慢呼吸的小圆点表示。
- **刚保存的纸条**：落入列表后以第二色光晕亮一次（约 2.2s，只改伪元素透明度）。
- **主题切换**：切换配色或明暗时整页交叉淡入（View Transitions），首次加载不做动画。
- **分页**：列表接近底部时自动加载下一页，加载中显示三点指示，失败时变为「加载失败，重试」。
- **减少动态效果**：遵守 `prefers-reduced-motion`，以上动画全部直接切换，呼吸点和加载点静止显示。

## 5. 页面骨架

| 视口 | 结构与尺寸 |
| --- | --- |
| ≥ 1024px | 最大容器 1080px；左侧悬浮纸面板侧栏 248px（距顶 24px、吸顶、圆角 24px），间距 48px，主列最大 720px；管理后台主列可扩至 980px |
| 768–1023px | 56px 毛玻璃吸顶顶栏（菜单、品牌、待确认计数、记一条）+ 左侧滑出导航抽屉；单列最大 768px（含左右 24px）；无底部导航 |
| < 768px | 52px 毛玻璃吸顶顶栏（品牌、待确认计数）；左右 16px 单列；底部悬浮坞 62px（左右 12px、底部 10px + 安全区、圆角 26px）；`viewport-fit=cover` 启用安全区 |

断点统一在样式入口维护，组件不各自定义断点。所有主列页的标题、收集框、筛选条、卡片左右对齐。

### 5.1 侧栏（桌面）

侧栏按「顶栏动作区 + 中间我的空间（轻滚动）+ 底部低频区」三区结构分层：

- **顶栏动作区**：品牌 → 并排一行的主色「记一条」（`N`）与「快速跳转」（`⌘K`）→ 主导航「收件箱 / 待归类 / 全部收藏」。当前导航项为强调色底，有待确认 AI 建议时仅「待归类」右侧显示第二色数量徽标。
- **我的空间**：细分隔线下方包含「常用项目」「标签」与「灵光日历」：
  - 常用项目默认展示最近活跃前 5 个，标题可直达 `/projects`，右侧提供「自定义」（即时搜索与星标开关 Popover，按 `user.id` 隔离并支持恢复自动推荐）与「+」入口；总项目多于展示数时显示克制的「全部项目」，仅确认全库 0 项目时显示「创建项目」。
  - 标签改为紧凑胶囊行（默认高频前 5 个），同样支持「自定义」置顶与「全部 →」（唤起 `#` 预填的命令面板）。
  - 灵光日历默认收起为单行入口 `灵光日历 · 本月 N 条 ▾`，点击平滑展开月历热力图；按日查看时自动展开并支持一键清除日期。
- **底部低频区**：细分隔线固定贴底，收纳「回收站」与账号菜单触发器（设置与会话、管理员管理后台、退出登录）。

### 5.2 手机导航

- 底部悬浮坞五格：「收件箱 / 项目 / 记一条 / 搜索 / 更多」。中央「记一条」为圆形主色按钮，上浮出坞并带一圈表面色描边，按下时加号旋转。
- 「更多」从底部弹出导航面板（抓手 + 遮罩）：账号入口（进入设置）、主导航、项目、回收站、管理后台、退出。
- 有待确认 AI 建议时，顶栏右侧显示「N 条待确认」胶囊，「更多」图标带数量徽标。
- 任一输入控件获得焦点时，悬浮坞下滑让位，避免软键盘遮挡保存操作。

### 5.3 页头与搜索

日常列表页（收件箱、全部收藏、待归类、项目、项目详情、回收站）复用统一页头：标题在左，桌面右侧为 240px 搜索框，聚焦扩至最多 360px。全局 ⌘/Ctrl+K 打开命令面板，默认聚焦其搜索框，Esc 关闭并恢复原焦点。在页头搜索框用输入法组词时，回车只用于确认候选词；提交后跳转 `/collections?q=…`。手机上搜索框只在全部收藏页常驻（底部「搜索」进入）。

收件箱标题下方显示随时段变化的问候与当天日期（例如「晚上好，11月18日 周三」）。

## 6. 核心组件

### 6.1 收集框（便签）

- 白色便签，左上角贴一段第二色纸胶带；无必填标题，默认不展开网址、用途、项目等表单。
- **静息 / 激活两态**：静息时正文一行；点击或聚焦编辑器、工具后平滑展开（正文最小 96px），边框转为主色调并加深阴影。激活后失焦不立即收起；有草稿或保存失败时保持展开；保存成功且焦点离开后回到静息。不因鼠标悬停抢焦点。
- **底部工具栏**（收集框与详情编辑器共用），分三组，组间以短竖线分隔：
  1. 「添加图片」「添加项目」（搜索选择项目，已选显示为胶带标签）、「附加链接」；
  2. 「Aa」（向上弹出：加粗、高亮，分隔线后为无序列表、有序列表）；
  3. 「更多」（撤销、重做；收集框另含「补一句用途」「附加网址」「可选标题」，开启 AI 时含「本条不参与 AI 整理」）。
- 工具只显示图标，均有可访问名称与悬停 / 聚焦提示；点击工具不丢失正文选区。所有浮层 Esc 关闭并返回触发按钮；手机上较大浮层横跨工具栏宽度、向下展开。
- **输入联想**：编辑器下方展示 `#` 标签或 `@` 项目候选，以主色浅底标记当前键盘选项。手机可点选。已选关联在正文外显示为可移除的短标签，窄屏换行。
- **右侧保存区**：桌面有输入时显示字数，手机仅在接近或超过上限时显示（警示色）；圆角主色发送按钮（上箭头，`aria-label="保存收藏"`，提示含 ⌘/Ctrl+Enter）。空白时禁用，保存中显示旋转指示，成功后短暂显示勾；图片仍在上传时也可以按保存，上传完成后自动保存（提示「图片传完后自动保存」）。失败保留内容与草稿并支持同幂等键重试。收件箱内联保存不弹提示条，新纸条直接出现在列表顶部；随手记面板与续写保存后弹出带「查看」的提示条。
- AI 开启入口：符合条件且未开启时，收集框底部为第二色渐变的入口条；已开启时为一行安静的状态。
- 尺寸：工具按钮桌面 34px、手机与触屏 40px；发送按钮桌面 40×34px、手机 48×40px，保证 360px 宽度内一行放下全部操作。

### 6.2 随手记

- 非收件箱页面触发「记一条」（手机坞中央、平板顶栏、桌面侧栏、快捷键 N）时，弹出「记一条」面板：手机为底部面板，电脑为居中对话框。面板内为去掉外框的收集框与一行说明，自动聚焦正文。
- 在收件箱触发时，原地聚焦内联收集框并滚动到可见位置，不刷新路由。
- 随手记与收件箱收集框共用同一草稿作用域；两者不会同时挂载，因此不产生平行草稿。关闭面板时未保存的内容保留为草稿。
- 快捷键 N 在输入框、输入法组合或已有对话框打开时不生效。

### 6.3 收件箱日志

- 收藏按本地日期分组，每组前为日期印章：
  - 桌面：撕页日历样式，顶条为「今天 / 昨天」或月份（今天为主色），中部为圆体日期数字，底部为星期；位于卡片左侧，滚动时吸顶。
  - 手机：印章平放为日期标题（数字 + 胶囊顶条 + 星期）。
- 组内卡片时间显示为钟点（例如 18:22）；其他列表页仍用相对时间。
- 筛选条为「全部 / 未读」胶囊分段控件 + 类型筛选按钮；类型筛选按需展开。收件箱为空且没有筛选时不显示筛选条。
- 已加载内容中有 3 条及以上未归入项目时，显示「N 条还没归入项目，一次整理完」入口；更少时直接在卡片上归类即可。
- 无收藏时显示瓶子插画与「保存的内容会出现在这里。」「先记下来，项目可以稍后再选。」；筛选无结果提供清除筛选；加载失败单独报错。

### 6.4 纸条卡片

- 结构顺序：时间（含未读点与整理状态胶囊，仅在无来源条或缩略图时才显示类型小图标）→ 可选自定义标题 → 正文（最多约 8 行）→ 精简来源条（`站点 · 标题` + 单行摘要，或干净 `domain/path` 短链接）→ 紧凑封面图组 → 搜索命中片段 → 单行统一底栏。
- **单行底栏顺序与上限**（与 macOS 桌面端同步）：
  1. **项目优先（最多 2 个，超出 `+N`）**：柔和圆点微胶囊（`● 项目名`），AI 自动归入仅以轻 `✦` 标记并在读屏标题注明；
  2. **标签其次（最多 3 个，超出 `+N`）**：低饱和纯文字 `#标签`；
  3. **右侧轻动作区**：有续写时展示 `N 条续写` 气泡，桌面端悬停轻现「续写」按钮；去掉重复的「查看全文」，点击整张卡片非交互区域、时间戳或标题即可进入详情。
- 仅在有可靠的自定义标题时展示标题，不把正文首句同时显示为标题与摘要。刚保存（8 秒内）的纸条以第二色光晕轻落一次。
- 「更多」菜单：标为已读 / 未读、续写、编辑 →（分隔）→ 移入回收站。桌面悬停或聚焦时强调；手机菜单以底部操作面板呈现。

分享卡提供四款 1080px 宽 2× 高清策展模板（`paper` 手帐纸笺 / `midnight` 胶片暗房 / `gallery` 展览海报 / `quote` 极简金句），根据含图与字数智能选中默认模板，提供圆钮色卡、清爽开关胶囊与一键「复制图片」。

### 6.5 项目色（纸胶带）

每个项目按 id 稳定映射到 6 种胶带色之一（`lib/projectTone.ts`），在侧栏色块、项目列表图块、卡片胶带、收藏详情的关联项目、项目详情标题上方的装饰胶带中保持一致。颜色仅为表现，不存储、不可编辑。

### 6.6 页面要点

- **项目列表**：分组列表，每行为项目色图块、名称、两行描述、状态点与收藏数。默认聚焦「进行中」，筛选为「进行中 / 已归档」（「已归档」合并展示已暂停与已结束并保留每行状态角标；无任何已归档项目时隐藏筛选栏）。
- **项目详情**：顶部操作条（返回、编辑项目）；标题上方项目色胶带；可展开的说明与关注点；编辑弹窗状态旁附自动归类与历史保留说明。
- **待归类**：每张卡下方连接一条整理托盘（虚线分隔），含 AI 建议卡片（第二色描边，「加入项目 / 忽略」与依据摘录）以及手动选择项目。
- **收藏详情**：顶部操作条按使用频率排列（返回；续写、编辑、生成卡片、标为已读 / 未读；分隔后为弱化的移入回收站，悬停才显示危险色；手机上吸顶并折叠为图标，保留可访问名称）。从列表进入时，导航高亮保持在来源页。正文与来源优先，随后依次为用途（未填写时只显示「补一句用途」入口，点击进入编辑并聚焦用途）、归类结果（归属明确时展示可点击的项目名，等待时说明原因；低频操作收进折叠的「更多管理与整理详情」）、续写线索时间线（按时间正序展示「当前」「来源」与「有一条已删除」占位）、折叠的提取内容与修订历史。编辑为显式动作；版本冲突以左右对比呈现，禁止简化为直接覆盖。
- **续写面板**：复用弹窗与底部面板（`Modal`），上方为来源提示卡（来源标题、可选摘录与不变说明），下方接入标准收集框与取消按钮。
- **整理模式**：延用纸条卡片和项目色。卡片同时提供可聚焦的操作按钮，手机手势和桌面快捷键共享同一套操作。减少动态效果时直接切换内容。
- **分享预览**：详情使用弹窗预览 4 款策展风格 1080px PNG，支持圆钮色卡切换、开关胶囊选图与可选来源/项目、「复制图片」「下载 PNG」及手机系统分享；超长正文末尾自然省略。
- **设置**：分卡片展示账号、界面外观（主题配色卡片 + 明暗分段）、AI 自动整理与额度、活跃设备会话（扩展设备附「浏览器扩展」徽标并支持单独撤销）。
- **浏览器扩展授权页（`/extension/pair`）与扩展弹窗**：沿用灵光手帐对折纸 / 纸面令牌风格，突出当前账号邮箱、设备名称、等宽大号 4+4 位配对码与固定最小权限框；扩展弹窗仅连接构建时固定的 Spark 服务地址，不提供自由填写服务地址栏，保存中就地禁用并反馈，成功后切换为带「在 Spark 中查看」与「继续收集」的完成视图。
- **回收站**：纸条列表，保留恢复与撤销；每条显示「剩余约 N 天后自动清理」（悬停显示精确时间）。服务端启用永久删除时提供弱化的危险色文字按钮，需二次确认；不显示搜索框和操作编号。
- **登录 / 注册 / 重置**：桌面为对折纸双栏，左侧强调色面板放品牌、瓶子插画与一句标语，右侧为表单；手机上插画收为顶部横幅，表单全宽。保留可见标签、足够高度的输入框与明确错误；测试适配器的模拟提示必须保留。

### 6.7 通用反馈

- **加载**：卡片形骨架屏 + 一行说明文字。
- **空态**：插画或小灵光标记 + 一句标题 + 一句说明 + 操作；措辞指明下一步，不道歉。
- **弹窗**：桌面居中、手机底部面板，均有标题、关闭按钮、Esc 关闭与焦点回收，打开时锁定页面滚动。
- **提示条**：桌面右下、手机悬浮坞上方；浅色模式为深色底，深色模式为浅一级表面；带操作（如「撤销」）时操作在右侧。

## 7. 实现与验证约定

- 共享组件负责共同样式与行为，页面不复制变体；被替代的样式及时删除，不并存两套皮肤。
- 路由、接口类型、认证、草稿隔离、版本冲突、幂等与安全渲染不因视觉调整而改变。
- 正式联调与验收通过 OrbStack Compose 进行，不以宿主机服务替代。仅查看样式时，经用户同意可在宿主机用测试适配器单独启动前端预览；该结果只代表界面表现，不作为联调验收。
- 复用现有类型检查、构建与行为测试；浏览器检查 1440 / 768 / 390px、长中文与长网址、空态与错误态、四套配色与深浅色，不用 `overflow-x: hidden` 掩盖布局问题。仅对新增行为或回归风险补充必要测试。
