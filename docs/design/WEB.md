# Web 页面与交互详细设计

首发覆盖电脑与手机浏览器。页面围绕收集、项目归类和找回三个任务。在线 Web 的唯一视觉依据为 [Web 视觉与交互规范](WEB-VISUAL.md)。

下文包含首发目标能力，不代表均已实现。当前联调范围及各外部服务的启用条件见 [ROADMAP](../ROADMAP.md)。当前界面不能显示可提交但必然失败的未来功能。

## 导航与地址

| 页面 | 前端路由 | 主要入口与内容 |
| --- | --- | --- |
| 登录、注册、找回密码 | /login、/register、/reset-password | 邮箱验证、邀请码、密码 |
| 收件箱 | /inbox | 快速收集、按天分组的收藏日志、整理情况 |
| 项目 | /projects、/projects/:id | 项目介绍、状态及关联资料 |
| 全部收藏 | /collections | 关键词和组合筛选 |
| 待归类 | /unclassified | 无有效项目关联资料及候选 |

| 收藏详情 | /collections/:id | 原始内容、用途、附件、项目和整理结果 |
| 回收站 | /trash | 恢复、永久删除与到期时间 |

桌面显示低干扰侧栏与单列资料流；手机底栏为收件箱、项目、记一条、搜索、更多；“记一条”在收件箱原地聚焦内联编辑器，在其他页面弹出共用收件箱草稿的随手记面板（桌面亦可按 N），两者不同时挂载，不建立平行草稿；输入时底栏避让软键盘。搜索词、筛选和排序放入 URL，详情返回恢复列表位置和筛选。管理员入口依据角色显示，后端独立鉴权。

## 邀请注册和找回密码

注册页要求邀请码、邮箱、注册验证码和密码。找回密码页申请另一用途的验证码。邮件申请被受理后，页面显示重发倒计时和有效期。更换邮箱会清空原验证码、倒计时和挑战，较早请求的回复不能覆盖新邮箱。到期后可重新申请；触发限流时按服务端返回的等待时间重试。生产界面由用户从自己的邮箱取码。重置成功后从登录页用新密码进入。

## 输入与收藏保存

收集框默认只突出正文与保存，无必填标题。空编辑区采用静息与激活状态，明确聚焦后展开并随内容自然增高；失焦不立即收缩，保存成功并移开焦点后才回到静息，有草稿或失败时保持展开。具体尺寸以 Web DESIGN 为准。底部使用分组图标工具栏，Aa 在按钮上方打开加粗/高亮小浮层，不插入顶部工具条；浮层保留编辑选区，支持 Escape 关闭并返回触发点。收集框、全部收藏的项目筛选、详情与待归类的手动归类共用分页项目选项。需要后续项目时点“加载更多项目”，保留当前选择。项目通过轻量选择器添加；用途、附加网址和可选标题由更多入口展开，收起不丢失输入。图片沿用收集框上传队列。在收集框和详情编辑器输入 `#` 可选择或新建账号内标签，输入 `@` 可选择进行中的项目。方向键移动、回车选中，手机可点选。选中后从正文移除触发词，把关联加入当前草稿；Escape 保留原文，中文输入法组词期间暂停联想。保存失败保留正文和已选关联。用途说明使用“补一句用途”。图片仍在上传时可以先按保存，上传完成后自动提交；有图片失败时停止并提示重试或移除。收件箱内联保存以新纸条出现在列表顶部作为反馈，不再弹提示条；随手记面板和续写保存后弹出带「查看」的提示条。提示条在鼠标悬停或获得焦点时暂停计时。

| 状态 | 界面行为 | 数据行为 |
| --- | --- | --- |
| 初始 | 当前提示“记下想法，或粘贴网址…”；图片接入后再扩展 | 空文档和附件列表 |
| 编辑中 | 展示格式工具、字数及图片预览 | 本地按账号保存草稿 |
| 上传中 | 每图进度、失败原因、重试和移除 | 保留本地文件，完成 OSS 校验后获取 ready 上传 ID |
| 可提交 | 内容或已就绪附件满足校验 | 提交固定 UUID 和幂等键 |
| 保存中 | 按钮忙碌、维持尺寸和输入 | 同一请求复用 UUID 和幂等键 |
| 成功 | 收藏出现在列表，显示已保存及整理状态 | 确认响应后清空该草稿和临时文件 |
| 请求失败 | 保留全部输入，提供重试 | 查询 UUID 或重放相同请求，避免重复创建 |
| 离线 | 明确显示本地草稿、待联网保存 | 恢复网络后由用户重试提交 |

图片最多 9 张、每张 5 MiB，文件选择、粘贴和桌面拖拽均使用同一验证逻辑。部分图片失败时，可以重试或移除后保存其余内容。页面关闭会有未保存提示，文件是否仍可恢复依浏览器持久化结果显示真实状态。

收起的收集框中，正文获得焦点才开始编辑。项目和标签移除按钮获得焦点时保持原位，鼠标或触摸在同一点按下和松开，一次激活即完成移除；键盘聚焦保留可见焦点，Enter 或空格执行操作。工具按钮需要展开面板时在按钮激活后展开。移除项目属于草稿修改，即使正文为空也应保留清空的选择，直到保存或明确重置。

此前「开启 AI」和项目胶带的「×」都曾在第一次点击时只展开输入框。浏览器先聚焦按钮，稍后才分发 click；父容器在聚焦时改变正文高度会移动按下的目标。验证此类改动时，从未激活的项目页开始，拆开按下和松开，核对两步之间按钮位置稳定，再核对首次移除和最终保存的项目。仅断言第二次点击后的界面会漏掉此回归。

草稿使用当前用户独立命名空间。退出时清除该账号的本地敏感缓存或按显式的保留选择加以隔离。收集框按收件箱或项目分别记录图片顺序、文件名、大小和已就绪上传标识。刷新或重开时按当前会话核对图片，仍就绪即可直接保存。已失效的图片保留文件名，提示移除并重选。上传未完成时关闭随手记需确认。原图数据、签名地址和凭据不写入草稿。刷新恢复只展示当前已认证账号的草稿。浏览器存储失败时持续显示提示，避免误报已保存草稿。

中文输入法组合输入期间禁止触发快捷提交。电脑录入支持 Cmd/Ctrl+Enter，手机明确保存按钮；焦点、屏幕键盘和附件弹层不能遮挡提交操作。

收件箱按本地日期分组展示收藏，每组以日期印章开头（今天、昨天或月日与星期），组内显示钟点时间。加载成功且无收藏时，列表区域显示瓶子插画与提示“保存的内容会出现在这里。”，不额外套卡片边框。筛选无结果仍提供清除筛选，加载和失败分别反馈，不混同为空账号。侧栏只有确认所有状态均无项目时才显示“创建项目”，存在已完成或暂停项目时保留“查看全部”。

### 今日重现与灵光日历

收件箱的「今日重现」按服务端顺序展示最多三张纸条，窄屏可横向滑动。每张标注重现原因，可打开全文、直接进入详情的项目归类区，或点「今天不再显示」。没有候选时收起整区；在设置关闭后，收件箱停止请求候选。跨日或切换账号后，重新按当前账号及本地日期读取。

灵光日历是收件箱的按日筛选，入口在收件箱页头「灵光日历」按钮：弹出月历热力图，点某天进入 `/inbox?date=...` 并收起，再点已选日期回到全部；按日查看时标题旁的日期胶囊可一键清除。手机与桌面使用同一入口。

桌面侧栏顶部为「记一条」与「搜索或跳转」（⌘/Ctrl+K）；导航行显示收件箱未读数与待归类条数（各读一页 20 条，超过显示「20+」，随收藏变更刷新）；中间为「项目」与「标签」（支持按账号自定义置顶，标签可折叠）；底部一行为账号菜单、回收站与设置。标签行末的「+N」打开 `#` 预填的命令面板按标签快速筛选。

从卡片、搜索结果、待归类或重现纸条主动进入详情时，更新该收藏的最近打开时间。每次进入详情只判断一次是否需要自动已读。用户随后标为未读会保留，即使入页请求仍在途。此记录独立于已读状态；预取、刷新、SSE 更新均不触发记录。

## 收藏卡片与详情

卡片按时间/未读、正文、来源条、项目/标签单行底栏排列，原文为主。已有来源条或图片缩略图时，顶部时间行不重复堆砌网址或图片小图标；点击时间戳或卡片空白正文均可进入详情，不再在每张卡片底部重复渲染「查看全文」。网址来源条在列表态展示精简的 `站点 · 标题` 与单行摘要（无富预览时展示无查询参数的短链接）。底栏按「项目（最多 2 个，柔和圆点微胶囊，`✦` 轻标示 AI 自动归入，超出 `+N`）→ 标签（最多 3 个低饱和 `#标签`，超出 `+N`）→ 续写计数气泡与桌面悬停「续写」」排列。文字卡不重复显示自动标题与首句；有可靠自定义标题时才突出标题。正文支持选择复制，详情链接、外链与操作按钮不互相嵌套。项目资料与搜索结果收到整理事件后更新对应卡片的状态与标题，保留搜索命中片段和分页位置。未归类状态不重复贴满卡片。图片与标签仅在对应能力和数据真实存在时显示。处理中展示简短状态，失败提供可操作入口；自动整理未接入时在详情集中解释，不将 skipped 当失败。AI 摘要主要在详情展开。

侧栏展示高频或用户置顶的标签胶囊（默认最多 5 个），支持搜索置顶与恢复自动推荐，同时可通过行末「+N」进入 `#` 命令面板按标签直达全部收藏。点击标签进入全部收藏，`tag_id` 随搜索和分页保留；已排除关联不显示在卡片上。

详情按原始材料、用途说明、项目与标签、提取内容、AI 整理分区。项目关联展示理由，suggested 提供“加入项目”和“忽略”，auto 提供确认和移除。用户操作映射为 include/exclude，恢复自动判断映射为 reset。

图片详情分别展示附件识别状态与本轮项目整理结果。图中文字出现在附件旁；画面描述按图片顺序作为正文中的「图片说明」，保留来源与编辑状态。可以单独修改或删除一段；并发修改时保留输入并展示最新说明。正文只读取服务端保存的说明，刷新后也尊重人工修改与删除。旧服务缺少图片说明字段时，附件旁仍显示可用的识别内容。部分结果有内容时显示「图片摘录」，空结果说明未取得可展示的摘录，并在符合资格时提供恢复操作。正常完成但没有内容时显示空结果。识别失败时按服务端诊断说明空响应、内容过滤、中断或响应无法解析等原因。刷新状态只读取已有记录。

服务端标记可恢复、图片理解已单独授权且收藏允许处理时，用户可对该附件点击“重新识别这张图片”。确认框注明文件名、向 DeepSeek 再次发送视觉副本及额度使用。旧版首次识别或恢复记录若解析失败、两字段为空且服务端确认上次已结算并允许恢复，可显式发起一次兼容恢复，确认框说明上次费用已结算及本次另计额度。资格缺失或用量待核对时隐藏此操作。

若恢复任务因额度竞争在模型派发前暂停且服务端确认没有用量，可再次确认，将同一任务重新排队。此次提交使用当前恢复记录标识和新的幂等键；响应丢失时重试沿用该次键。排队和执行中仅查看状态。

新版文字授权允许按有依据的图片材料自动归入进行中项目，必要时创建主题项目。详情区分归入已有项目和新建后归入；列表及项目页显示当前有效的自动归属。后台通知同步项目列表、资料和待归类页面，支持人工移除或更改。等待图片时说明项目匹配尚未完成；只有服务端确认本轮已使用图片材料时才显示「本次整理使用了图片识别结果」。项目建议区显示图中文字或 AI 画面描述的原句，详情同时标明附件名。完成且没有待确认建议时可手动归类，部分失败时展示阶段状态。

打开详情后，账号的整理事件触发当前收藏和提取结果刷新。返回前台、恢复连接和手动「刷新状态」也可获取最新结果，无需页面轮询。

编辑提交 content_version。重新进入编辑时沿用账号内草稿。发现草稿版本落后或保存收到 409 时，展示服务器和本地的完整正文、标题、用途、来源与关联。可复制或保留草稿并退出，明确舍弃或按所比较的服务器版本覆盖提交。覆盖时保留服务器现有附件。会话明确允许网页提取时才显示重新获取操作；关闭后仍展示来源链接和已有预览。自动整理更新仅刷新对应区域，正文编辑器继续保留本地输入。

已保存的收藏可在详情中生成分享卡片。浏览器本地渲染 1080px 宽 2× 高清 PNG，提供「手帐纸笺」「胶片暗房」「展览海报」「极简金句」四款策展模板（有图默认「展览海报」，无图且不超过 60 字默认「极简金句」，其余默认「手帐纸笺」；超长正文末尾直接省略，不加「节选」），按附件顺序最多九张且支持开关胶囊逐张选图，支持「下载 PNG」「复制图片」（`ClipboardItem` 特性检测及温和降级提示）与可用时的「系统分享」。缩略图取自当前会话的同源 JPEG 接口；加载失败时提示重试或选择仅文字，取得完整预览后才能导出。勾选后可加入有效项目名或省略查询参数与片段的来源网址；用途、附件文件名、图片访问地址及正文中的裸 URL 均不导出。

打开详情且加载成功后设置已读，可手动标为未读。图片使用私有短期地址，过期按需刷新。原网页在新标签页打开，保留来源信息。

活跃收藏卡片、卡片操作菜单（快捷键 `f`）和详情顶部操作区均提供「续写」入口；回收站中不提供续写。点击「续写」打开正常收藏收集框（桌面为居中弹窗，手机为底部面板），展示来源标题、不重复于标题的摘录以及「原笔记将保持不变」提示。默认勾选来源当前有效且仍在项目列表中的归属项目，并允许继续增删或一键「清空项目」，保存仅提交用户最终选择的 `project_ids` 与 `source_collection_id`。按来源分别隔离未提交草稿与取消操作，提交失败时保留输入并沿用原 `collectionId` 与 `idempotencyKey` 重试。当一条收藏所属线索还有其他活跃成员时，卡片显示简洁续写气泡（`N 条续写`）并直达详情时间线；详情按时间正序展示同一线索的全部成员、标注「当前」与「来源」、支持「加载更多」，已被移入回收站的成员仅显示「有一条已删除」占位而不暴露标题或正文。

## 项目体验

新建项目要求名称，描述和关注点提供用途示例，允许先保存后补充。项目为空时直接提供收藏入口。自动关联依赖描述，界面解释补充描述能改善归类。项目列表默认聚焦「进行中」，筛选 Tab 精简为「进行中 / 已归档」（「已归档」合并展示已暂停与已结束并保留每行状态角标；无任何已归档项目时隐藏 Tab 栏）。

项目详情显示名称、描述、关注点、状态、资料数和筛选。编辑状态旁提供明确说明：进行中参与自动归类并显示在快捷列表；暂停或结束后停止自动归类，历史收藏完整保留。暂停与完成项目仍可浏览资料，用户可主动添加收藏。修改描述后提示后续整理使用新描述，历史重新匹配在明确选择范围后执行。顶部操作栏提供「删除项目」入口，弹窗明确提示「项目下的笔记和图片都会保留，只解除关联」，须输入精确项目名称后按当前版本提交（`DELETE /projects/{id}?base_version=...`）；若当前编辑区存在未保存草稿或未完成上传的临时图片，删除前先提示可取消保存/清空或点击「先转存到收件箱」（转存失败或收件箱已被占用时保留原项目草稿并阻止误删，亦不覆盖已有收件箱草稿），未处理前须勾选放弃才允许继续；取消删除不改动任何草稿。删除成功或遇到 404 已删除时仅按目标项目与目标会话清理置顶和草稿引用、保留其他草稿数据并失效项目、收藏和搜索缓存后返回项目列表；路由按项目 ID 隔离实例，页面切换或版本冲突异步刷新均不串用其他项目页面或会话。

待归类资料可以批次浏览，首期逐条确认。没有任何项目时提示创建项目，收藏继续正常保存。低把握关联展示候选理由，用户可以直接新建项目或保持待归类。

收藏详情的「归类结果」根据实际项目关系显示归属。手选、已确认或自动建立的关联都可直接打开项目；只有标签或未确认建议时仍显示待归类。没有落入项目的收藏显示当前原因，以及适用的一项操作。更多管理入口可查看整理过程、调整项目或暂停本条整理。

用户打开符合条件的已分析网页时，详情使用原有结果自动补归类，通过独立写请求核对决定版本与幂等键。列表读取和预取保持只读。成功后更新归属、项目列表和项目资料；遇到版本冲突重读最新决定。此次补归类不重新向模型发送内容。

整理模式从待归类页进入，按游标续取当前账号的待归类收藏。可以把一条收藏加入一个或多个项目、稍后再看，或仅在本轮移出；撤销最近一次归类时，以服务端回执为准。并发编辑导致版本冲突时保留新决定，并提示重新读取。手势与快捷键均有对应按钮。

收件箱的 AI 整理入口紧邻日常录入操作，手机首屏也可开启。首次开启沿用设置页相同的知情同意流程，不自动处理历史收藏。生成待确认项目建议时，即使已经切换到别的页面，仍能看见带操作的完成提示并直接查看依据；关闭提示不会清除建议。待确认页、收件箱入口和导航计数共享同一份分页结果。新建议到达、最后一条被确认或忽略，以及断线重连后，当前页从服务端同步最新建议与可用操作。没有项目建议的整理结果不要求用户确认。提示不抢夺键盘焦点，减少动态效果偏好下保留文字和操作。

## 搜索与筛选

桌面日常页标题右侧提供搜索入口，提交后进入全部收藏页的 URL 查询。Cmd/Ctrl+K 打开命令面板，可查找收藏、跳转项目或切换外观；手机导航也提供入口。方向键选择，回车执行，Escape 返回原焦点。列表中 J/K 移动卡片焦点，Enter 打开，E 编辑，R 切换已读，N 记一条。输入框、编辑器、输入法组合和已打开的弹层保留自己的按键行为。输入法组合期间不触发跳转，手机保持独立搜索页。搜索输入防抖建议 300 毫秒，取消已过期请求，只有最新查询更新列表。关键词与项目、标签、阅读状态、类型和时间取交集。清除筛选恢复列表，当前筛选体现在 URL。

展示命中字段与片段，并对用户输入按纯文本安全高亮。无结果时只给一个下一步：有筛选时「清除筛选」，否则「去收件箱」。还有下一页时，结果计数写作「N 条以上」。网络失败提供重试，保留当前筛选和已有结果。

分页列表（收件箱、全部收藏、待归类、回收站）在接近底部时自动加载下一页，保留按钮作为无障碍与失败重试入口。

首发搜索对中文短语和英文关键词做字面查找。用户输入语义式长问题时保留原查询，结果表现按实际命中，后续语义搜索通过同一入口演进。

## 回收站和设置

移入回收站提供短暂撤销入口（编辑中不显示删除按钮，阻止重复提交并在撤销失败或版本冲突时刷新最新状态）。恢复成功后回到正常详情。会话的 `purge_enabled` 为 true 时才展示到期信息（「剩余约 N 天后自动清理」）与单条「永久删除」、多选「彻底清除所选」和一键「清空回收站」操作；字段缺失或为 false 时提示未开启永久删除，同时保留恢复操作及既有操作回执。界面不展示内部操作编号。

单条与批量永久删除均弹出不可恢复二次确认（多选基于已勾选项固定快照；「清空回收站」按当前会话完整枚举本人全部分页并按 ID 稳定去重，仅收集最小 `{ id, resourceVersion }` 快照并在确认弹窗展示精确条数，枚举任一分页失败即中止而不部分误删；确认后绝不扩大已确认快照，新移入回收站或已在其他端恢复的收藏不受影响）。批量执行限制并发、阻止并发恢复/重复触发，遇到账号/会话切换或页面离开时立即中止后续派发并隔离状态；仅 `202` 受理不视为附件已清完，保留本批准确受理/失败计数并在 sessionStorage 保留全部未完成（`queued`/`running`）任务状态与有限条已完成历史，网络或瞬时失败保留原幂等键与原版本安全重试，版本冲突/已恢复条目刷新列表提示。提交后（sessionStorage 仅保存最小收藏 ID、操作 ID 与状态，不持久化真实笔记标题）按状态分别提示等待/正在清理附件（失败后台自动重试）或「笔记和附件已永久删除，无法恢复」，退出或换号时按会话隔离清理回执与缓存。

文字整理与图片理解分别授权。将识别结果提供给第三方文字模型生成项目建议，需要开启图片理解并确认包含图中文字、AI 画面描述的新文字授权；原图只由图片理解服务处理。旧授权继续覆盖原有范围；已授权图片材料生成建议的用户可维持确认流程。只有明确同意新版归档说明后，图片材料才能用于自动关联或创建主题项目。最新版文字整理授权（`spark-ai-extension-archive-v1`）进一步累积「网页收藏归类」披露：将已保存并确认的标题、纯文本选文与用途发送给第三方文字模型以匹配或创建主题项目（不发送网址与网页抓取正文，手选项目优先）；旧授权不自动启用网页归类。详情页仅对明确携带扩展来源标记的记录显示来源提示；对于具备可用材料的活跃网址收藏（含未知来源旧条），用户可点击「按网页内容归类」先核对当前标题/选文/用途并确认授权后显式调用 `POST /collections/{id}/organization/web-archive`；缺乏材料时引导补充标题或用途；网页任务失败或受阻且账本无预留记录（`web_archive_retry_available: true`）时才显示「重试网页归类」入口并随新幂等键派发；若已结算的网页归类旧失败（`invalid_model_output`）或模型输出过长截断（`model_output_truncated`）具备 `web_archive_recovery_available: true`，详情页仅提供单一「重试网页归类」入口，在用户确认将再次使用 AI 额度后以 `{ run_id, base_decision_version }` 与 `Idempotency-Key` 调用 `POST /collections/{id}/organization/web-archive/recover`（网络未确认时沿用原键重发，阻止连续双击，Worker 零派发额度竞争后仍可按新键重排同一恢复行）。对已结算网页结果、待核用量（`usage_uncertain`）、显式标 `web_archive_retry_available: false` 的二次失败或缺少资格的记录，不展示假重试；正常非网页成功或部分成功仍保留原有手动重整入口。设置区分历史版本与当前授权。更新授权本身不启动历史任务。设置显示全局开关、当前额度、单条排除入口。关闭后手动分类和普通搜索仍可使用。

界面外观提供四套主题配色（薄荷晨雾、海盐蓝、抹茶奶白、樱花雾粉）与「跟随系统 / 浅色 / 深色」两项独立设置，分别保存到当前账号，收到服务端确认后生效。登录与恢复会话时应用账号偏好，浏览器只记住最近一次服务端确认的配色和明暗偏好。退出、会话过期及重新打开公共页面时沿用它，换号成功后使用新账号的偏好。

设置页可按 Markdown 或 JSON 下载本人数据。两个格式均为 ZIP，限流时显示可再次下载的时间。手机通过浏览器的添加到主屏入口安装后，从收件箱启动，应用内缺少有效会话时进入登录页。

会话列表显示设备名称、创建时间、到期时间和当前设备，支持单独撤销（撤销非当前设备前先就地二次确认）。扩展连接设备标记「浏览器扩展」标签（`Spark 浏览器扩展 (Chrome)` / `Spark 浏览器扩展 (Edge)`），macOS 桌面客户端标记「macOS 桌面端」标签（`Spark macOS 桌面端`），找回密码或单台撤销完成后对应网页、扩展与桌面会话均失效。

### macOS 桌面端授权（`/desktop/pair`）

macOS 桌面应用通过系统浏览器打开 `/desktop/pair#challenge=<base64url>`（仅传由 `spark-desktop-pair-v1:` 加 `verifier` 计算得到的 43 位无填充 base64url 摘要，不传 `verifier` 与访问令牌，也不传自由文本设备名）。页面首帧解析后立即移除 `window.location.hash`；未登录时先提示前 8 位构成的 4+4 位大小写敏感比对码，引导进入 `/login` 或 `/register` 并在登录后返回该页。已登录时清晰展示当前账号邮箱、目标设备「Spark macOS 桌面端」、4+4 位比对码、允许的操作范围（快速保存与查看收藏、项目、标签、搜索与图片附件上传/查看，不含设置、授权、导出、永久删除或管理能力）以及 30 天绝对到期时间（无静默续期，到期需重新授权）；点击「确认授权绑定」向 `POST /api/v1/desktop/grants` 提交 `expected_account_id`（Web 端不接触也不保存桌面 Bearer 凭据）；账号切换或配对失效时拒绝确认并提示回桌面端重新发起连接。

### 浏览器扩展授权（`/extension/pair`）与扩展保存反馈

浏览器扩展通过 URL fragment 传递 `#challenge=<base64url>&browser=<chrome|edge>` 打开 `/extension/pair`（不传 `verifier` 与访问令牌）。页面首帧解析后立即移除 `window.location.hash`；未登录时先提示 4+4 位大小写敏感配对码，引导进入 `/login` 或 `/register` 并在登录/注册后返回该页。已登录时展示当前账号邮箱、目标扩展设备、4+4 位配对码与固定最小权限范围（读取进行中项目 ID/名称，保存标题、HTTP(S) 网址、纯文本选区与用途，不读取已有收藏/回收站/导出/管理能力），点击「确认授权绑定」向 `POST /api/v1/extension/grants` 提交 `expected_account_id`；账号切换或配对失效时拒绝确认并提示回扩展重发连接。

扩展弹窗在点击「保存到 Spark」后立即锁定按钮并在底部视口内展示保存中状态（在持久化草稿前阻止双击）。仅当收到服务端真实成功回执后，才就地切换为与发起账号绑定的完成视图（展示已保存标题、网址、「在 Spark 中查看」，按是否手选项目展示「已归入所选项目」或「已保存到收件箱，在收藏详情查看归类结果」，重放时仅提示「已保存，无需重复提交」），隐藏保存按钮；点击「继续收集」按当前标签页重新初始化，防止误点发出空标题重复请求。未知网络中断与可重试失败保留原 ID 与原幂等键重试。

## 邀请码管理

管理员选择 CSV、输入批次名，预览有效行数及行级错误。确认按钮在预览有效且错误为空时可用。提交后显示批次统计，支持禁用批次或单码。邀请码正文由管理员原始文件分发，后台列表展示使用和有效状态。

「选择 CSV 文件」支持 Tab 聚焦、回车和空格打开，旁边显示「未选择文件」或已读入的文件名，读屏可获取该状态。取消选择保留原内容，可重选同一文件。手动编辑 CSV 后清除文件名；读取、校验和提交期间禁用选择按钮。

导入或提交失败保留当前预览和文件，预览过期提示重新校验。列表在并发兑换后刷新 used_count，禁用操作显示影响范围。

预算配置中的「保存预算」与同一行的输入框等高、底边对齐。窄屏空间不足时控件随行换行。

## 交互验收矩阵

至少验证 390、768、1440 像素宽度，包含长中文、超长网址、多层列表、9 图、空态和错误态。小屏正文重排，操作按钮可触达，页面避免横向溢出。手机相册选择和粘贴使用真实设备复测。

所有输入提供可访问名称，键盘可到达主要操作，对话框管理焦点并支持关闭，错误同时用文字说明。加载状态与成功提示可由辅助技术感知。动画遵循减少动态效果偏好。

颜色、间距、控件状态在 Web 设计系统集中维护，MyGo 的配色可作为参考。浏览器验证记录页面、视口、操作步骤和结果，交互缺陷修复后重测对应路径。
