# Web 页面与交互详细设计

首发覆盖电脑与手机浏览器。页面围绕收集、项目归类和找回三个任务。在线 Web 的唯一视觉依据为 [Web 视觉与交互规范](WEB-VISUAL.md)。2026-11-16 实现的轻量输入与原文优先方案（双态编辑器、底部工具栏、格式浮层、快捷搜索）已通过 OrbStack 实际浏览器验证；2026-11-18 的「灵光手帐」视觉重构（收件箱日志、随手记、手机悬浮坞、主题配色）已通过类型检查、构建、行为测试与测试适配器预览，尚待 OrbStack 真实联调复验。

下文包含首发目标能力，不代表均已实现。当前仅文字/网址、项目、手动关联、字面搜索与软删除恢复等首个纵向批次可联调；图片上传、标签、自动整理、AI 预算和永久删除等按 ROADMAP 后续接入。当前界面不能显示可提交但必然失败的未来功能。

桌面显示低干扰侧栏与单列资料流；手机底栏为收件箱、项目、记一条、搜索、更多；“记一条”在收件箱原地聚焦内联编辑器，在其他页面弹出共用收件箱草稿的随手记面板（桌面亦可按 N），两者不同时挂载，不建立平行草稿；输入时底栏避让软键盘。搜索词、筛选和排序放入 URL，详情返回恢复列表位置和筛选。管理员入口依据角色显示，后端独立鉴权。

## 邀请注册和找回密码

注册页要求邀请码、邮箱、注册验证码和密码。找回密码页申请另一用途的验证码。邮件申请被受理后，页面显示重发倒计时和有效期。更换邮箱会清空原验证码、倒计时和挑战，较早请求的回复不能覆盖新邮箱。到期后可重新申请；触发限流时按服务端返回的等待时间重试。生产界面由用户从自己的邮箱取码。重置成功后从登录页用新密码进入。

## 输入与收藏保存

收集框默认只突出正文与保存，无必填标题。空编辑区采用静息与激活状态，明确聚焦后展开并随内容自然增高；失焦不立即收缩，保存成功并移开焦点后才回到静息，有草稿或失败时保持展开。具体尺寸以 Web DESIGN 为准。底部使用分组图标工具栏，Aa 在按钮上方打开加粗/高亮小浮层，不插入顶部工具条；浮层保留编辑选区，支持 Escape 关闭并返回触发点。项目通过轻量选择器添加；用途、附加网址和可选标题由更多入口展开，收起不丢失输入。未来接入图片附件时复用同一收集框；当前不显示可操作的上传或标签入口。用途说明使用“补一句用途”。

| 状态 | 界面行为 | 数据行为 |
| --- | --- | --- |
| 初始 | 当前提示“记下想法，或粘贴网址…”；图片接入后再扩展 | 空文档和附件列表 |
| 编辑中 | 展示格式工具、字数及图片预览 | 本地按账号保存草稿 |
| 上传中 | 每图进度、失败原因、重试和移除 | 保留本地文件，完成 OSS 校验后获取 ready 上传 ID |
| 可提交 | 内容或已就绪附件满足校验 | 提交固定 UUID 和幂等键 |
| 保存中 | 按钮忙碌、维持尺寸和输入 | 同一请求复用 UUID 和幂等键 |
| 成功 | 收藏出现在列表，显示已保存及整理状态 | 确认响应后清空该草稿和临时文件 |
| 请求失败 | 保留全部输入，提供重试 | 查询 UUID 或重放相同请求，避免重复创建 |
| 离线 | 明确显示本地草稿、待联网保存 | 恢复网络后由用户重试提交 |

图片最多 9 张、每张 5 MiB，文件选择、粘贴和桌面拖拽均使用同一验证逻辑。部分图片失败时，可以重试或移除后保存其余内容。页面关闭会有未保存提示，文件是否仍可恢复依浏览器持久化结果显示真实状态。

草稿使用当前用户独立命名空间。退出时清除该账号的本地敏感缓存或按显式的保留选择加以隔离。刷新恢复只展示当前已认证账号的草稿。浏览器存储失败时持续显示提示，避免误报已保存草稿。

中文输入法组合输入期间禁止触发快捷提交。电脑录入支持 Cmd/Ctrl+Enter，手机明确保存按钮；焦点、屏幕键盘和附件弹层不能遮挡提交操作。

收件箱按本地日期分组展示收藏，每组以日期印章开头（今天、昨天或月日与星期），组内显示钟点时间。加载成功且无收藏时，列表区域显示瓶子插画与提示“保存的内容会出现在这里。”，不额外套卡片边框。筛选无结果仍提供清除筛选，加载和失败分别反馈，不混同为空账号。侧栏只有确认所有状态均无项目时才显示“创建项目”，存在已完成或暂停项目时保留“查看全部”。

### 今日重现与灵光日历

收件箱的「今日重现」按服务端顺序展示最多三张纸条，窄屏可横向滑动。每张标注重现原因，可打开全文、直接进入详情的「关联项目」，或点「今天不再显示」。没有候选时收起整区；在设置关闭后，收件箱停止请求候选。跨日或切换账号后，重新按当前账号及本地日期读取。

桌面侧栏底部和手机「更多」面板顶部提供月历，支持跨月和跨年翻页。深浅表示当天的收藏数量，悬停、触摸或键盘聚焦日期时显示准确条数，读屏名称包含日期和数量。用方向键在当月移动，回车选择日期。收件箱标题旁可清除日期筛选，列表高亮对应日期印章。查询使用服务端返回的当地零点边界，遇到整天跳过的日期直接显示空结果。

从卡片、搜索结果、待归类或重现纸条主动进入详情时，更新该收藏的最近打开时间。此记录独立于已读状态；预取、刷新、SSE 更新均不触发记录。

## 收藏卡片与详情

卡片按时间/未读、正文、来源、项目排列，原文为主。文字卡不重复显示自动标题与首句；有可靠自定义标题时才突出标题。正文支持选择复制，约 8 行后提供查看全文，详情链接、外链与操作按钮不互相嵌套。类型和未归类状态不重复贴满卡片。图片与标签仅在对应能力和数据真实存在时显示。处理中展示简短状态，失败提供可操作入口；自动整理未接入时在详情集中解释，不将 skipped 当失败。AI 摘要主要在详情展开。

详情按原始材料、用途说明、项目与标签、提取内容、AI 整理分区。项目关联展示理由，suggested 提供“加入项目”和“忽略”，auto 提供确认和移除。用户操作映射为 include/exclude，恢复自动判断映射为 reset。

编辑提交 content_version。409 冲突时展示服务器当前内容与本地草稿，允许复制、比较和基于当前版本重新提交。自动整理更新仅刷新对应区域，正文编辑器继续保留本地输入。

打开详情且加载成功后设置已读，可手动标为未读。图片使用私有短期地址，过期按需刷新。原网页在新标签页打开，保留来源信息。

## 项目体验

新建项目要求名称，描述和关注点提供用途示例，允许先保存后补充。项目为空时直接提供收藏入口。自动关联依赖描述，界面解释补充描述能改善归类。

项目详情显示名称、描述、关注点、状态、资料数和筛选。暂停与完成项目仍可浏览资料，用户可主动添加收藏。修改描述后提示后续整理使用新描述，历史重新匹配在明确选择范围后执行。

待归类资料可以批次浏览，首期逐条确认。没有任何项目时提示创建项目，收藏继续正常保存。低把握关联展示候选理由，用户可以直接新建项目或保持待归类。

整理模式从待归类页进入，按游标续取当前账号的待归类收藏。可以把一条收藏加入一个或多个项目、稍后再看，或仅在本轮移出；撤销最近一次归类时，以服务端回执为准。并发编辑导致版本冲突时保留新决定，并提示重新读取。手势与快捷键均有对应按钮。

收件箱的 AI 整理入口紧邻日常录入操作，手机首屏也可开启。首次开启沿用设置页相同的知情同意流程，不自动处理历史收藏。生成待确认项目建议时，即使已经切换到别的页面，仍能看见带操作的完成提示并直接查看依据；关闭提示不会清除建议。待确认列表支持下次登录后继续处理。没有项目建议的整理结果不要求用户确认。提示不抢夺键盘焦点，减少动态效果偏好下保留文字和操作。

## 搜索与筛选

桌面日常页标题右侧提供搜索入口，Cmd/Ctrl+K 聚焦，Escape 收起并恢复原焦点；提交进入全部收藏页的现有 URL 查询，不另建搜索状态体系。输入法组合期间不触发跳转，手机保持独立搜索页。搜索输入防抖建议 300 毫秒，取消已过期请求，只有最新查询更新列表。关键词与项目、标签、阅读状态、类型和时间取交集。清除筛选恢复列表，当前筛选体现在 URL。

展示命中字段与片段，并对用户输入按纯文本安全高亮。无结果时提示调整关键词、清除筛选或查看待归类。网络失败提供重试，保留当前筛选和已有结果。

首发搜索对中文短语和英文关键词做字面查找。用户输入语义式长问题时保留原查询，结果表现按实际命中，后续语义搜索通过同一入口演进。

## 回收站和设置

移入回收站提供短暂撤销入口。回收站显示剩余保留时间，恢复成功后回到正常详情。永久删除二次确认，提交后显示清理中并从可访问内容中移除，清理失败由后台继续重试。

AI 首次启用解释将处理的文字、链接、图片及服务提供方，用户明确开启后自动整理新收藏。设置显示全局开关、当前额度、单条排除入口。关闭后手动分类和普通搜索仍可使用。

界面外观提供四套主题配色（薄荷晨雾、海盐蓝、抹茶奶白、樱花雾粉）与「跟随系统 / 浅色 / 深色」两项独立设置，立即生效并保存在当前浏览器，不随账号同步。

设置页可按 Markdown 或 JSON 下载本人数据。两个格式均为 ZIP，限流时显示可再次下载的时间。手机通过浏览器的添加到主屏入口安装后，从收件箱启动，应用内缺少有效会话时进入登录页。

会话列表显示设备名称、创建时间、到期时间和当前设备，支持撤销。找回密码流程完成后重新登录，之前的会话失效。

## 邀请码管理

管理员选择 CSV、输入批次名，预览有效行数及行级错误。确认按钮在预览有效且错误为空时可用。提交后显示批次统计，支持禁用批次或单码。邀请码正文由管理员原始文件分发，后台列表展示使用和有效状态。

「选择 CSV 文件」支持 Tab 聚焦、回车和空格打开，旁边显示「未选择文件」或已读入的文件名，读屏可获取该状态。取消选择保留原内容，可重选同一文件。手动编辑 CSV 后清除文件名；读取、校验和提交期间禁用选择按钮。

导入或提交失败保留当前预览和文件，预览过期提示重新校验。列表在并发兑换后刷新 used_count，禁用操作显示影响范围。

预算配置中的「保存预算」与同一行的输入框等高、底边对齐。窄屏空间不足时控件随行换行。

## 交互验收矩阵

至少验证 390、768、1440 像素宽度，包含长中文、超长网址、多层列表、9 图、空态和错误态。小屏正文重排，操作按钮可触达，页面避免横向溢出。手机相册选择和粘贴使用真实设备复测。

所有输入提供可访问名称，键盘可到达主要操作，对话框管理焦点并支持关闭，错误同时用文字说明。加载状态与成功提示可由辅助技术感知。动画遵循减少动态效果偏好。

颜色、间距、控件状态在 Web 设计系统集中维护，MyGo 的配色可作为参考。浏览器验证记录页面、视口、操作步骤和结果，交互缺陷修复后重测对应路径。
