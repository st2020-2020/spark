## 1. 目标与成功标准

让输入不打断思路，让熟练用户更快，让喜欢的内容可以分享出去。

- 不离开键盘即可完成「输入 → 打标签 → 选项目 → 保存」。
- 主要列表操作都可以用键盘完成。
- 分享卡片在四套配色下排版正确，默认不暴露项目与用途。

## 3. 方案设计（概要）

### 3.1 标签与输入即标记

- 实现契约已有的 `/tags` 与 `/collections/{id}/tags`；迁移新增 `tags` 与 `collection_tags`（按 DATA.md）。
- 编辑器扩展：输入 `#` / `@` 时弹出联想；选中后生成关联，正文中不保留触发字符；输入法组合期间不触发。
- AI 整理优先使用用户已有标签（PRODUCT 已有规则）；人工增删优先。

### 3.2 分享卡片

- 详情页「生成卡片」：在浏览器内用 Canvas 绘制点阵纸背景、纸条正文、日期印章与小瓶子标志，跟随当前配色；长文截断并注明「节选」。
- 通过系统分享或下载保存，不上传服务器。

### 3.3 键盘与命令面板

- 列表：`J` / `K` 切换，`Enter` 打开，`E` 编辑，`R` 切换已读，`N` 记一条（已实现）。
- 命令面板：搜索收藏、跳转项目、切换配色与明暗；设置页提供快捷键说明。

### 3.4 外观偏好同步

- 用户偏好新增 `palette` 与 `theme` 字段；登录后以服务端为准，本机未登录时沿用本地存储。
