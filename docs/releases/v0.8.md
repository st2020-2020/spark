## 设备边界

默认登录流程已按首次试用反馈调整，直登客户端 `e60413a6` 与后端 `d2686d8f` 已通过双账号隔离实机验收。用户在应用内填写 Spark 邮箱与密码，登录成功直接进入随手记。Go 宿主仅向固定 Spark API 提交，使用 `POST /api/v1/desktop/login` 换取有效期 30 天的设备会话。钥匙串仅保管设备令牌。直登复用现有账号的密码验证与登录限流，设备权限沿用下列业务路由，数据库沿用 v19。

原生直登的验收行为如下。全新启动时显示登录表单；成功后进入随手记，全程留在应用内。错误密码显示统一提示，限流按返回的等待时间引导重试。失去网络或设备会话过期时保留本机笔记。同账号重新登录可继续补传，换账号时隔离原账号发件箱。此前已通过的网页配对验收覆盖旧版入口。

旧客户端配对时由 Go 宿主生成一次性配对凭据，系统浏览器仅收到摘要。用户比对两端短码后，由已有 Web 会话经同源及 CSRF 校验批准。桌面在五分钟内一次兑换，令牌仅存 macOS 钥匙串。单台设备固定 30 天到期，届时需重新认证。远程网页和 WebView JavaScript 均拿不到令牌。改密、禁用账号和撤销单台设备后验证对应访问失效。

首批新增 `/desktop/grants`、`/desktop/token` 和 `/desktop/session`，路径均位于 `/api/v1` 下。桌面设备按方法及路由获得下列业务权限。Web 会话和扩展凭据继续使用各自的授权路径。

| 能力 | 桌面设备首批业务路由 |
| --- | --- |
| 收集、浏览、查找 | POST、GET `/collections`，GET `/collections/{id}`，GET `/projects`、`/tags`、`/search` |
| 上传及取回本人附件 | POST `/uploads`，GET `/uploads/{id}`，POST `/uploads/{id}/complete`，GET `/attachments/{id}/download` 和 `/attachments/{id}/thumbnail` |

管理接口、设备授权以及第三方 AI 同意继续留在对应的 Web 授权边界内。完整主窗口后续按具体交互对齐编辑、归类、回收站、偏好与事件订阅，现有整理事件路径为 `/api/v1/organization/events`。一期桌面按普通收藏写入，沿用当前账号的授权与预算。扩展独有的网页来源标记仅用于扩展收藏。

## 离线保存和图片

- ⌘↵ 在本地内容和图片都可靠落盘后才提示已收下。按账号保存读缓存和发件箱；切换账号隔离未发送项，撤权时暂停，原账号重新登录后继续。
- 首次发送前冻结收藏 UUID、幂等键及请求内容。已发但响应丢失时在服务端七天回放窗口内重放原请求。超过窗口或遇同 UUID 冲突，先按原账号和 ID 核对；无法确认时保留本地稿和待核对状态。首次联网前的纯离线存放不消耗服务端回放窗口。
- Go 客户端按签发 URL、请求头、准确 MIME 和字节长度发送 PUT，设置 HTTP ContentLength。对象存储请求独立于 Spark 鉴权，禁止附带 Spark 令牌、Cookie 或跟随重定向。浏览器 CORS 不适用于原生 Go 请求。上传登记仍有效时复用原登记补签；complete 返回 202 后轮询至 ready 再绑定收藏。
- 桌面首批使用现有分页读取与搜索刷新缓存。完整增量同步另行设计。系统剪贴板建议需尊重隐私标志与敏感来源，截图或剪贴板内容仅在用户实际收下时进入发件箱。
