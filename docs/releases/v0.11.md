# v0.11.0 回收站彻底清除

基线为 v0.10.1。用户可以永久删除一条笔记、删除勾选的多条笔记，或清空本人回收站。回收站里的笔记及其附件一经清理无法恢复。

## 删除范围

单条操作在对应笔记上发起。多选操作仅包含已选中的笔记。清空回收站会先读取全部分页，再给出本次要清除的准确条数。取消确认时不提交删除；确认后新进入回收站的笔记留待下次处理。

三种操作都复用现有永久删除接口。服务端按当前登录账号、笔记 ID、回收站状态和资源版本受理。确认期间被恢复或变更的笔记须重新核对，每条已受理的笔记都有自己的清理回执。附件清理进度以回执为准。

## 验收与部署

验证范围包括超过一页的回收站、取消和重复确认、部分失败后的重试、其他账号与已恢复的笔记，以及已受理和清理完成这两个状态。仅以合成数据执行删除验收。

数据库沿用 v20。线上启用条件见 [v0.10 运维要求](v0.10.md#运维要求)。永久删除关闭时，用户仍可浏览回收站和恢复笔记。
