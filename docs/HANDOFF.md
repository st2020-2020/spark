# Spark 开发交接

设计基线 v1，更新于 2026-11-18。面向在本工作空间接手的产品、前端、后端、测试及部署开发者。

Spark 帮助个人收集网上的文字、网址和图片，自动提取内容、归类到正在进行的项目，再通过项目和搜索找回。首发为国内用户使用的邀请内测 Web 应用，适配电脑与手机。腾讯云 4 核 4GB 承载后端，附件使用阿里云 OSS。MyGo 桌面程序是后续联网客户端的基础。

## 当前代码事实

桌面业务入口保留在根目录 `main.go`，视图在 `internal/app`，SQLite 条目操作在 `internal/entries`，规则与远程模型适配在 `internal/ai`。已支持单机文字、链接、单图保存和基础整理。

在线版首个纵向批次已实现在 `server/` 独立 Go module 与 `apps/web/`：账号和开发邮件验证、事务化邀请兑换、会话及密码重置、项目、文字/网址收藏、用途、人工项目关联、关键词搜索、已读、软删除与恢复。PostgreSQL、API、Web 统一通过 OrbStack Compose 运行，运维 CLI 与数据库集成测试也在容器中执行，说明见 [server/README.md](../server/README.md)。最新验证结果见 [ROADMAP](ROADMAP.md)，首批实现不等于 M1 至 M4 全部完成。

M3 的文字 AI 整理子集已实现。平台启用、用户同意且有额度时，保存文字或用途说明可触发 River Worker 生成标题、摘要和带引文的项目建议，由用户确认或忽略。默认关闭，未配置时返回 `skipped / integration_not_configured`。隔离 OrbStack 环境已通过本机 Magpie 的一条 DeepSeek 路由验证真实调用与结算。生产尚未启用，完整验证边界见 [ROADMAP](ROADMAP.md)。

真实邮件、OSS/多图、网页正文、OCR、标签、永久删除/到期清理、完整管理后台及多端同步尚未实现。OpenAPI 仍包含后续待实现操作，不能以契约或前端页面存在判断后端能力。桌面 `Entry` 到在线 `Collection` 的显式导入属于后续工作，不直接复用桌面存储。

现有 `DESIGN.md` 和 `UX-CONTRACT.md` 描述当前 MyGo 版本。在线 Web 以本交付文档为实现依据。运行中的本地数据位于忽略目录 `data/`，开发测试使用独立数据库和临时附件。

## 决策状态

| 状态 | 内容 |
| --- | --- |
| 用户已确定 | 个人产品、自注册加管理员导入邀请码、自动识别归类、项目关联、手机 Web 优先、Go 云端、MyGo 桌面、阿里云 OSS |
| 按对话解释采用 | 服务器和用户在国内，暂不考虑海外 |
| 本轮设计默认 | 邮箱密码、一码一人、轻量富文本、每条 9 图且每图 5 MiB、50,000 字、30 天回收站 |
| 本轮工程默认 | OpenAPI 3.0.3、UUID、UTC 时间、北京时间配额日、用户内隔离、分阶段任务、人工归类优先 |
| 集成前待提供 | 服务器具体地域及系统、域名和访问方式、邮件服务、OSS 配置、模型/OCR 服务和预算 |
| 实测后确定 | AI 自动采纳阈值、资源限制、性能容量、正式服务承诺 |

默认值允许按用户后续反馈调整。依赖版本由实施者验证后固定在依赖锁文件，供应商服务选择记录在集成交付中。

## 实施入口

当前先收敛 ROADMAP 的 M0 与首个纵向批次：在 OrbStack 容器栈验证导入邀请码、注册、创建项目、保存文字或链接、手动归类、搜索找回，并处理前端依赖告警。随后按里程碑补齐未实现能力。本机测试部署不得恢复宿主机 PostgreSQL、API 或 Web 作为容器替代；已有宿主测试资料与逻辑备份保留，真实 `data/` 不参与在线版测试。

前后端可基于契约分工开发，外部集成通过测试适配器返回标明为模拟的结果。正式内测验收使用真实邮件、OSS、OCR 和模型服务。每个任务应交付代码、所需迁移、相应测试、可执行验证命令以及实际验证结果。

协作时以 `git status` 和工作区实际文件为准，先确认其他 agent 正在编辑的范围。任务提交范围由当次指令决定。每阶段完成后更新 ROADMAP 的状态及验证证据，文档中的目标值与实际结果分开记录。

## 文档与契约验证记录

2026-11-16 已使用 openapi-spec-validator 0.9.0、openapi-schema-validator 0.9.0、jsonschema 4.26.0 完成以下检查。

- OpenAPI 3.0.3 结构、引用和 52 个唯一 operationId。
- 富文本及模型输出 JSON Schema，自带有效样例与未知字段拒绝。
- 不支持的文档版本、节点、标记，以及超出附件数量的无效请求样例。
- 路径参数声明、管理接口会话声明和写入接口 CSRF 声明。
- Markdown 本地链接、代码块闭合和 Git 差异空白检查。

这些检查针对交付契约。客户端生成及编译在 M0 完成，实际业务行为和真实云服务验证按 DELIVERY 用例逐步交付。
